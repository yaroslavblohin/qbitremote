# История изменений

## 0.2.17 — 2026-10-29

- Пункты контекстного меню торрентов приведены к одному шрифту, высоте строк и отступам; запуск, остановка и удаление используют общий стиль с пиктограммами.
- Убраны двойной разделитель после удаления и линии между группами. Группы выделяются приглушёнными заголовками того же размера. Для всего меню используется одна область прокрутки.
- Обновлён снимок контекстного меню в документации.

## 0.2.16 — 2026-10-29

- Документация приведена в соответствие с множественным выбором и импортом/экспортом RSS; устранены устаревшие указания на действия только с одной строкой.
- Пересозданы восемь скриншотов текущей версии: список, файлы, скорость, Graphite, White, групповое меню, множественный выбор и импорт RSS.
- Сценарий обновления скриншотов дополнен новыми состояниями и восстановлением переменной множественного выбора. Самостоятельная инструкция Release актуализирована. Поведение приложения не изменено.

## 0.2.15 — 2026-10-29

- Импорт и экспорт правил RSS в JSON, совместимом с qBittorrent. Экспорт получает свежие правила с сервера, включая неизвестные клиенту поля.
- Перед импортом — проверка структуры, предпросмотр имён и выбор замены совпадений. По умолчанию существующие правила пропускаются. Ленты не создаются и остальные правила не удаляются.
- Отчёт о числе сохранённых и пропущенных правил; при ошибке показаны имя правила и частичный результат. Пустой экспорт поддерживается; пустой импорт не выполняется. Лимит импортируемого файла — 8 МиБ, поддерживается UTF-8 BOM.
- Тесты JSON, Unicode, совместимости полей, конфликтов, частичной ошибки и сохранности экспортного файла при ошибке HTTP.

## 0.2.14 — 2026-10-29

- Множественный выбор торрентов: Ctrl+щелчок, Shift-диапазон с учётом текущей сортировки, Ctrl+A для видимого списка, Escape для сброса.
- Групповой запуск, остановка, удаление с перечнем целей и контекстные операции, включая лимиты скорости, категории, теги и очередь. Переименование и экспорт доступны для одного торрента.
- Правый щелчок внутри выделения сохраняет группу; по другой строке выбирает только её. Скрытые фильтром и удалённые торренты исключаются из выбора; переключение сервера очищает выбор.
- Проверены выбор диапазона после сортировки и HTTP-команды групповых действий для API 4.x/5.x.

## 0.2.13

- Иконка приложения встроена в ресурсы EXE для отображения в Проводнике и ярлыках. Размеры: 16, 24, 32, 48, 64, 128 и 256 пикселей; используется общий рисунок с окном и треем.

## 0.2.1

- Темы оформления: Marine LLM Theme и Graphite Theme. Переключение через меню «Вид» с сохранением выбора.
- Компактный тёмный интерфейс с цветными статусами и тематической иконкой окна и трея. Скорости и число завершённых торрентов размещены рядом с поиском и кнопками.
- Главное меню «Файл», «Правка», «Вид», «Серверы», «Справка»; настройки доступны через меню.
- Несколько профилей серверов, автоподключение к выбранному профилю, редактирование сохранённых подключений.
- 38 настраиваемых колонок. Сохраняются видимость, порядок, ширина, колонка и направление сортировки. Перетаскивание заголовка меняет порядок; щелчок в любой части заголовка сортирует.
- Исправлен выбор торрента щелчком по тексту строки.
- Размер панели сведений настраивается и сохраняется; переключение пустых вкладок не уменьшает панель.
- Дерево файлов с раскрываемыми папками, поиском и командами раскрытия и сворачивания всех папок.
- Исправлено ложное сообщение об отказе сервера при успешном добавлении `.torrent` в новых версиях qBittorrent.
- Запрещён запуск нескольких экземпляров в одной сессии Windows; блокировка автоматически снимается при завершении процесса.
