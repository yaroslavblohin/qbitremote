# qBit Remote

Клиент на Rust для управления удалённым qBittorrent через Web UI API. Текущая реализация и сборка — **только Windows**.

## Возможности

- Тёмный GUI на egui/eframe: боковые фильтры, сортируемая таблица, поиск, сведения о выбранном торренте.
- Меню «Файл», «Правка», «Вид», «Серверы», «Справка». Настройки приложения — в «Правка → Настройки приложения», параметры qBittorrent — в «Серверы → Настройки qBittorrent», масштаб — в «Вид». «Файл → Выход» завершает приложение, включая режим сворачивания в трей.
- «Вид → Колонки»: 38 колонок списка qBittorrent, включение чекбоксами, «Все» и «По умолчанию». Выбор, порядок, ширина и сортировка сохраняются; для большого набора доступна горизонтальная прокрутка. Щелчок по заголовку сортирует по значению, перетаскивание меняет порядок. Поля, которые версия Web API не возвращает, отображаются как «—».
- Подключение к qBittorrent 4.1+ / 5.x, cookie-сессия, обновление каждые 3 секунды. Запросы выполняются вне потока GUI.
- Именованные профили серверов с отдельными зашифрованными паролями. Переключение — в меню «Серверы»; одновременно активен один сервер. Добавление, изменение, сохранение и удаление профилей — в «Серверы → Управление серверами». Поля доступны для редактирования и при подключении: изменение адреса, логина или пароля отключает текущий сервер, название можно менять без отключения. После изменения учётных данных нажмите «Сохранить профиль» и «Подключиться».
- Автоподключение к последнему выбранному профилю при запуске включено по умолчанию и отключается в настройках. Старое сохранённое подключение автоматически становится первым профилем. Если пароль не сохраняется, для входа может потребоваться ввести его снова.
- Высота панели информации о торренте изменяется перетаскиванием верхней границы и сохраняется. Пустые вкладки и загрузка данных не меняют её размер; длинное содержимое прокручивается внутри панели.
- Запуск, остановка, добавление magnet/HTTP-ссылок и `.torrent`-файлов. Путь сохранения относится к серверу.
- Удаление с подтверждением; удаление файлов на сервере по умолчанию выключено.
- Подробности торрента: свойства, трекеры, пиры, HTTP-источники, файлы с приоритетами и переименованием, карта частей, график скорости. Команды перепроверки, анонса, очереди, последовательной загрузки, принудительного запуска, автоуправления, категорий и тегов, переноса данных на сервере, ограничений раздачи и экспорта `.torrent`.
- Лимиты скачивания и отдачи — глобальные и для выбранного торрента. Ввод в КиБ/с, 0 снимает ограничение. Переключение альтернативного режима; расписание и альтернативные значения — в настройках сервера.
- Поиск через серверные плагины: результаты, страницы, остановка, удаление поиска, установка/обновление/включение плагинов. Загрузка результата через движок поиска, если сервер возвращает его имя.
- RSS: папки, ленты, статьи, прочтение, перемещение, обновление, URL и интервал; создание, редактирование, копирование, переименование, удаление правил и просмотр подходящих статей.
- Основной журнал и журнал пиров с фильтром; управление категориями и тегами; редактор параметров, возвращённых `app/preferences`, с отправкой только изменённых значений.
- Расширенные панели загружаются по мере открытия и обновляются раз в 5 секунд. Функции зависят от версии и конфигурации сервера; ошибки API показываются в интерфейсе. Полное совпадение со всеми версиями настольного qBittorrent не заявляется: расширенные параметры пока используют имена API, RSS не имеет импорта/экспорта файлов правил, таблица торрентов пока с одиночным выбором.
- Клиент не открывает папки и загруженные файлы удалённого сервера в локальном проводнике, не запускает серверные программы и не требует сетевых дисков. Управление файлами торрентов выполняет сам сервер через API.
- Windows tray: двойной щелчок открывает окно; меню содержит «Открыть» и «Выход». Крестик по умолчанию скрывает окно в трей. Если трей создать не удалось, окно закрывается обычным образом.
- Системный HiDPI через winit/egui и дополнительный масштаб 80–150% в настройках.
- Сохраняются адрес, имя пользователя, масштаб, настройка трея и геометрия окна. После успешного входа пароль сохраняется зашифрованным через Windows DPAPI для текущей учётной записи Windows. Сохранённый пароль привязан к адресу сервера и имени пользователя. Cookie остаются только в памяти.
- Флажок «Сохранять пароль на этом компьютере» включён по умолчанию. Если снять его, сохранённый пароль удаляется из настроек при ближайшем сохранении. Настройки автоматически сохраняются каждые 3 секунды и при штатном выходе.

## Запуск и сборка

Нужны Rust stable (MSVC), Visual Studio Build Tools с workload C++ и Windows SDK.

```powershell
cargo run
cargo test
cargo clippy --all-targets -- -D warnings
cargo build --release
```

Исполняемый файл: `target/release/qbit-remote.exe`. Для распространения достаточно этого EXE. Пока нет установщика, подписи и автообновления.

## Подключение

1. В qBittorrent включите Web UI и задайте учётные данные.
2. Откройте «Серверы → Управление серверами» в клиенте.
3. Укажите адрес вроде `https://seedbox.example.org` или `http://192.168.1.10:8080`. Поддерживается путь reverse proxy, например `https://example.org/qbit/`.
4. Введите логин, пароль и нажмите «Подключиться».

Проверка TLS включена. Самоподписанные сертификаты без доверенной цепочки не принимаются. HTTP передаёт учётные данные без шифрования; для удалённого доступа используйте HTTPS или доверенный VPN. Перенаправления не выполняются: указывайте конечный адрес Web UI. При потере связи клиент покажет ошибку и предложит повторное подключение.

## Структура

- `src/app.rs` — интерфейс и состояние окна.
- `src/api.rs` — HTTP API, авторизация, фоновый поток и тесты локального HTTP-сервера.
- `src/model.rs` — модели и форматирование.
- `src/tray.rs` — Windows tray, изолированный от сетевого слоя.
- `src/credentials.rs` — шифрование пароля Windows DPAPI и привязка к серверу/пользователю.
- `src/remote.rs`, `src/remote/pages.rs` — подробности торрентов, удалённые разделы, формы, кэш запросов и обработка ответов.

## Проверки

Автоматические тесты проверяют URL reverse proxy, отклонение некорректных адресов, cookie-авторизацию, кодирование пароля, команды для API 4.x/5.x, отказ входа и HTTP-ошибки. Тесты не обращаются к реальному серверу.

Дополнительные тесты проверяют успешный HTTP 204 в qBittorrent 5.2, восстановление зашифрованного пароля после сериализации настроек, отсутствие открытого пароля в настройках, изоляцию учётных записей/серверов, отказ от сохранения, повреждение шифротекста и загрузку старых настроек. `live_server_read_only` исключён из обычного запуска; для него требуются явно заданные `QBIT_TEST_ADDRESS`, `QBIT_TEST_USERNAME`, `QBIT_TEST_PASSWORD`.

Для приёмки на рабочем сервере: подключение, добавление разрешённого тестового торрента, остановка/запуск, удаление без файлов, потеря связи; перенос окна между мониторами с DPI 100/150/200%; закрытие в трей, восстановление двойным щелчком, выход через меню.

`cargo run --features ui-smoke` открывает тестовое окно с явно обозначенными фиктивными данными, проверяет создание трея, сохраняет `dist/ui-smoke.png` и завершает приложение. Этот режим не входит в обычную сборку и не подключается к серверу. Переменная окружения `QBIT_SMOKE_ZOOM=1.5` позволяет проверить увеличенный масштаб.

`QBIT_SMOKE_TRAY=hidden` включает нативную проверку: 10 циклов закрытия в трей/восстановления и выход из скрытого окна. Значения `visible` и `minimized` проверяют выход из открытого и свёрнутого окна. Используются те же обработчики восстановления и выхода, что и в меню трея, без кликов мышью. Тестовые окна используют отдельный файл состояния `dist/ui-smoke-state.ron`.

Все три сценария с ограничением времени выполняет `./scripts/test-tray.ps1` (нужен доступный рабочий стол Windows). Скрипт проверяет штатное завершение процесса, а при зависании завершает только свой тестовый процесс и сообщает ошибку.

Документация: [qBittorrent Web API](https://github.com/qbittorrent/qBittorrent/wiki/WebUI-API-(qBittorrent-5.0)), [eframe](https://docs.rs/eframe/0.31.1/eframe/), [tray-icon](https://docs.rs/tray-icon/0.20.1/tray_icon/).

Расширенные операции сверены с контроллерами `src/webui/api` и панелями свойств официального qBittorrent, ревизия `a87f8f9c282e7341b1f4f9e9a5a66c869d2366a6`. Реализация GUI на Rust самостоятельная. Локальная исследовательская копия `.reference/` исключена из поставки.

Тесты расширений проверяют единицы и границы скорости, реальные HTTP-запросы лимитов на mock-сервере, ошибки 404/отклонение команд, IPv6-адреса, отбрасывание ответов старой сессии, объединение повторных запросов и сохранение правок при отказе API. Read-only интеграционный тест дополнительно читает 18 расширенных API-разделов. `QBIT_SMOKE_PAGE=speed` и `settings` выбирают тестовую страницу для снимка интерфейса.
