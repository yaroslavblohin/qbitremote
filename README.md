# qBit Remote

Клиент на Rust для управления **удалённым qBittorrent** через Web UI API. Текущая версия — **0.3.26**. Приложение доступно для Windows и macOS.

## Быстрый запуск

1. На Windows запустите [qbit-remote.exe](Release/qbit-remote.exe). На Mac распакуйте универсальный ZIP, перенесите `qBit Remote.app` в «Программы» и откройте его. [Установка на macOS](docs/MACOS.md).
2. Включите Web UI на сервере qBittorrent и разрешите доступ с компьютера клиента.
3. Создайте профиль подключения: адрес, имя пользователя и пароль. Поддерживаются адреса вида `https://seedbox.example.org` и пути reverse proxy, например `https://example.org/qbit/`.
4. Нажмите «Подключиться». Список торрентов обновляется автоматически; ручное обновление доступно через «Файл → Обновить список».

Автоподключение и сохранение пароля включены по умолчанию. В Windows пароль защищён DPAPI текущей учётной записи, на macOS используется Keychain. Cookie хранятся только в памяти. Для удалённого доступа используйте HTTPS или доверенный VPN: HTTP не шифрует учётные данные.

Крестик окна по умолчанию скрывает приложение. Окно можно восстановить из трея Windows, строки меню macOS или Dock. В строке меню macOS используется монохромный значок qbr. Для завершения работы выберите «Файл → Выход» или «Выход» в меню значка.

## Вкладки серверов

Кнопка «+» в строке вкладок справа от боковой панели открывает список сохранённых серверов и команду «Новый сервер…». У каждого сервера своя вкладка и своё подключение. Списки торрентов и включённые графики скорости обновляются и в фоновых вкладках. При переключении сохраняются выделение и открытая панель информации. Команды, настройки qBittorrent и открываемые из Проводника файлы относятся к текущей вкладке.

Крестик закрывает вкладку и завершает её подключение. Профиль можно снова открыть через «+» или меню «Серверы». При запуске восстанавливаются открытые вкладки, их порядок и активная вкладка. Для каждого сервера запоминаются колонка и направление сортировки, вкладка панели информации и выбранный торрент. Панель восстанавливается после загрузки списка, если этот торрент ещё есть на сервере. Автоподключение этих серверов задаётся в настройках. После обновления со старой версии откройте нужные профили через «+», чтобы приложение запомнило набор вкладок.

## Возможности

- Профили серверов, автоподключение, сохранение пароля через DPAPI или Keychain.
- Поиск, фильтры, сортировка, настройка видимости, ширины и порядка колонок; множественное выделение и групповые команды.
- Стрелки перед «Загрузка» и «Отдача» показывают направление передачи. Стрелка после заголовка показывает направление сортировки активной колонки.
- Добавление `.torrent`, magnet/HTTP-ссылок, результатов серверного поиска и статей RSS через диалог выбора файлов.
- Запуск, остановка, удаление с подтверждением, перепроверка, обновление анонса, очередь, принудительный запуск, последовательная загрузка и приоритет крайних частей.
- Дерево файлов с приоритетами отдельных файлов и целых папок, переименованием на сервере и открытием локально доступных данных.
- Свойства торрента, карта частей, пиры, трекеры, HTTP-источники и индивидуальный график скорости.
- Категории и теги, комментарии, перенос данных на сервере, ограничения раздачи, экспорт `.torrent` и копирование magnet.
- Глобальные и индивидуальные лимиты скачивания/отдачи, альтернативный режим скорости.
- Серверный поиск и управление поисковыми плагинами; RSS-ленты, статьи, правила автоматической загрузки, импорт/экспорт правил JSON.
- Основной журнал и журнал пиров, компактный редактор настроек удалённого qBittorrent с отправкой только изменённых значений.
- Трей, три темы, системный HiDPI и дополнительный масштаб интерфейса 80–150%.

Функции зависят от версии и конфигурации сервера. Поддерживаются различия команд API qBittorrent 4.x/5.x; полное совпадение со всеми версиями настольного qBittorrent не заявляется. Клиент не предоставляет локальные функции сервера и не монтирует сетевые ресурсы самостоятельно.

## Управление торрентами

Панель после поиска содержит кнопки: **добавить → запустить → остановить → удалить → выше в очереди → ниже в очереди**. Кнопки квадратные, с подсказками; добавление доступно без выделенного торрента. Стрелка вверх на панели — фиолетовая, вниз — бордовая. В контекстном меню стрелки «Ниже в очереди» и «В конец очереди» красные; пиктограмма загрузки синяя.

Счётчик рядом с заголовком показывает число видимых торрентов с учётом раздела и поиска. Счётчики боковой панели показывают общее количество в каждом разделе независимо от поиска. Числа оформлены тем же шрифтом, что и соответствующие подписи. Цвет счётчика заголовка совпадает со счётчиком выбранного раздела в боковой панели. Загрузка обозначается синим цветом: стрелка, счётчики, состояние и прогресс используют общий оттенок темы.

Щелчок выбирает торрент, Ctrl добавляет или исключает его из выбора, Shift выделяет диапазон, Ctrl+A выбирает все видимые строки; в текстовом поле сочетание выделяет текст. Количество выбранных показано в нижней строке состояния. При смене сервера выделение очищается; скрытые фильтром и удалённые торренты исключаются из выбора.

Панель сведений относится к последнему выбранному торренту. Её высота изменяется перетаскиванием верхней границы и сохраняется. Крестик справа или Esc скрывает панель и снимает выделение. Вкладки: «Общее», «Файлы», «Пиры», «Трекеры», «График», «HTTP-источники».

В начале вкладки «Общее» показаны карта частей, легенда и счётчики всех и готовых частей. Серый цвет обозначает отсутствующую часть, синий — загружаемую, зелёный — готовую. Лимиты и сведения о торренте находятся ниже в той же области прокрутки. Если в сохранённом профиле была выбрана вкладка «Части», откроется «Общее».

В «Общем» неизвестная доступность торрента показана как «—» с пояснением при наведении. Известное значение — число распределённых копий, а не процент: одна копия может состоять из частей у разных пиров.

Ссылки в полях «Комментарий», «Magnet-ссылка» (`magnet_uri`) и «Трекер» (`tracker`) кликабельны, включая переносы строк. HTTP/HTTPS открываются в браузере по умолчанию; magnet и UDP — через системный обработчик соответствующей схемы, если он установлен. Правый щелчок открывает меню копирования точного адреса, открытия и отмены. Во вкладке «Трекеры» такие же действия доступны для адресов и ссылок в сообщениях; даже при сокращённой подписи используется полный URL. Служебные строки DHT/PeX/LSD остаются обычным текстом.

На серверах с Web API 2.13.0 и новее стрелка слева от URL раскрывает адреса интерфейсов удалённого qBittorrent, с которых он выполняет анонсы. Для каждого адреса показаны версия BT, состояние и ответ трекера. «След. анонс» показывает время до запланированного запроса, «Мин. анонс» — время до самого раннего допустимого запроса. Правый щелчок по адресу позволяет скопировать IP и порт. Стрелка раскрытия появляется, когда сервер передал хотя бы один адрес анонса.

Неизвестные отрицательные числовые значения в свойствах заменяются прочерком. Специальные значения лимитов раздачи показаны по смыслу: `-1` — «Без ограничения», `-2` — «По настройкам сервера»; нулевой лимит раздачи сохраняется как ноль.

«Дополнительные сведения» показывают только поля, отсутствующие в основной таблице. Повторы удаляются по смыслу API-ключей, включая `comment`, даты, объёмы передачи, время активности и приватность. Основные свойства имеют приоритет; null дополняется доступным значением из списка торрентов. Одинаковые значения разных величин не считаются дублями.

Меню «Вид → Колонки» содержит выбор полей и кнопки «Все»/«По умолчанию».

Правый щелчок открывает общее прокручиваемое меню. Команды запуска, остановки, очереди, удаления и лимитов доступны для группы; переименование торрента и экспорт — для одного выбранного торрента. Удаление требует подтверждения, флажок удаления файлов на сервере по умолчанию выключен.

Для перемещения в очереди она должна быть включена на сервере. Клиент сравнивает позиции до и после команды: последний торрент ниже не перемещается, а завершённые раздачи с прочерком в колонке очереди не считаются следующими позициями очереди загрузки.

Во время переноса данных между папками состояние `moving` отображается как **«Перемещение»**.

Состояние раздачи без активной передачи отображается как **«Ожидание» бирюзовым текстом**. Полоса завершённого торрента остаётся зелёной. Готовые части в карте также зелёные. В списке пиров показаны флаги стран, для неизвестной страны — «Весёлый Роджер».

Сообщения операций и ошибки сохраняются в отдельной **«Консоли приложения»**, закрытой по умолчанию: «Вид → Консоль приложения…» или одноимённый пункт контекстного меню торрента. Доступны очистка и копирование последних 300 записей. Это журнал клиента, а не командная оболочка сервера.

## Добавление и выбор файлов

В Windows назначьте `qbit-remote.exe` обработчиком `.torrent` через «Открыть с помощью». При повторном запуске файл передаётся уже работающему экземпляру и окно восстанавливается из трея. Поддерживаются несколько файлов, пробелы и кириллица. Сохраняйте путь к EXE при обновлениях, чтобы ассоциация продолжала работать.

На Mac откройте `.torrent` в Finder через «Открыть в программе → qBit Remote». Приложение также регистрируется как обработчик magnet-ссылок. Файлы и ссылки поступают в диалог добавления активного сервера.

**Для добавления с предварительным выбором файлов нужен qBittorrent 5.2+ с API метаданных.** Если API недоступен, клиент показывает ошибку и не начинает загрузку автоматически. Уже существующий торрент следует менять во вкладке «Файлы».

До подтверждения диалога сервер получает только метаданные, содержимое не скачивается. Для magnet/HTTP-ссылки получение списка файлов может занять время. Несколько торрентов обрабатываются по очереди; отмена или закрытие диалога до подтверждения не добавляет торрент.

- Выберите файлы или папки в дереве, при необходимости задайте серверную папку, категорию и теги.
- Флажок папки меняет выбор всех вложенных файлов, включая скрытые поиском и свёрнутые. Поиск не меняет уже выбранные файлы.
- Приоритеты: «Не скачивать», «Обычный», «Высокий», «Максимальный». Приоритет папки применяется ко всем потомкам, «Разный» обозначает смешанное состояние.
- Кнопки и пункты списка приоритетов используют один шрифт 12 точек и центрированы; ширина кнопки фиксирована. Обычный приоритет зелёный, высокий оранжевый, максимальный красный, пропуск и смешанный — приглушённые.
- Нижняя строка показывает количество и размер выбранных файлов. Без выбранных файлов добавление недоступно.

**«Начать загрузку после добавления» включён по умолчанию.** Загрузка начинается после нажатия «Добавить торрент». Снимите флажок для добавления в остановленном состоянии. Выбор файлов, приоритеты и состояние запуска передаются серверу одним запросом. Автоматические правила RSS используют собственные параметры и не открывают этот диалог.

## Открытие файлов через сопоставления

Подключите серверный ресурс в Windows и задайте правила в профиле подключения либо в «Серверы → Настройки qBittorrent → Сопоставление папок сервера с этим компьютером».

| На сервере | На клиенте Windows |
| --- | --- |
| `/downloads/complete` | `Y:\torrents\complete` |
| `/downloads` | `\\NAS\Downloads` |

Папка должна уже открываться в Проводнике. Клиент не скачивает файлы через Web UI API. Правила сохраняются автоматически отдельно для каждого профиля; «Обзор…» выбирает папку на компьютере.

При первом открытии файлов торрента раскрыты только корневые папки: видны их файлы и свёрнутые вложенные папки. При смене торрента используется то же начальное раскрытие; обновление списка не сбрасывает ручной выбор. Поиск временно показывает подходящие ветки.

«Доступность» файла показана в процентах доступных частей по сведениям сервера и отличается от прогресса загрузки. Неизвестное значение (в том числе `-1`) отображается как «—» с пояснением при наведении. У папок прочерк означает, что доступность не рассчитывается.

В дереве файлов доступны двойной щелчок и команды «Открыть файл», «Открыть папку», «Открыть содержащую папку». Жёлтая кнопка рядом с поиском открывает сопоставленную папку самого торрента по `content_path`, а для одиночного файла — содержащую его папку. Если сервер не сообщает `content_path`, используется папка сохранения. Щелчок по значку папки раскрывает дерево. Чтобы переименовать файл или папку на сервере, щёлкните по строке правой кнопкой и выберите «Переименовать файл…» или «Переименовать папку…». Команды открытия доступны и из списка торрентов; для многофайлового торрента можно выбрать файл в папке.

Выбирается самое длинное совпадение по целым компонентам серверного пути; регистр Unix учитывается, Windows — нет. Корневая папка уже входит в имя файла API и повторно не добавляется. Недоступный ресурс, отсутствующий файл и отсутствие правила записываются как ошибки в консоль; успешное открытие не создаёт плашку над таблицей. Частично загруженный файл открывается только по существующему имени.

## Скорость и графики

Лимиты задаются глобально, для одного торрента или выделенной группы. Ввод — в КиБ/с, **0 снимает ограничение**. Для группы указанный лимит применяется к каждому торренту, а не делится между ними. Альтернативный режим переключается отдельно; расписание и альтернативные значения задаются в настройках сервера.

При каждом запуске запись всех графиков **выключена**. У каждого торрента собственный чекбокс записи, история и масштаб. Общий график включается отдельно и не включает индивидуальные. При включённой записи данные собираются из фонового опроса примерно раз в 3 секунды независимо от вкладки, открытой панели и работы в трее. При выключенных графиках история не собирается.

Доступны координатная сетка, диапазон времени, масштаб времени/скорости, сброс и переход к концу. Колесо мыши меняет масштаб времени, Ctrl+колесо — скорости, перетаскивание перемещает видимый диапазон. История хранится в памяти с момента включения записи. Выключение освобождает её; отключение сервера, закрытие его вкладки и завершение приложения очищают историю.

На снимках показан синтетический пример четырёх минут уже идущей загрузки: почти ровная скорость скачивания, небольшие колебания и независимые просадки отдачи. В начале записи уже получено около 14% торрента, в конце — 64%. Размер, объёмы и последние значения графиков согласованы с таблицей и статистикой. Общий график дополнительно учитывает торрент, который был полностью скачан до начала записи.

В BitTorrent можно одновременно скачивать новые части и отдавать уже полученные и проверенные. Поэтому зелёная линия у незавершённого торрента допустима: речь не об отдаче ещё отсутствующих данных. Это предусмотрено [спецификацией BitTorrent (BEP 3)](https://www.bittorrent.org/beps/bep_0003.html#peer-protocol).

## RSS и настройки сервера

«Импорт правил…» принимает JSON UTF-8 до 8 МиБ и показывает предпросмотр перед отправкой. Совпадающие имена по умолчанию пропускаются; флажок замены разрешает перезапись. Другие правила не удаляются, ленты не создаются автоматически. «Экспорт правил…» сохраняет правила в JSON. Пути в правилах относятся к серверу; включённые правила могут сразу начать загрузки.

Настройки сервера сгруппированы по разделам: загрузки, скорость, соединение, BitTorrent, очередь и раздача, Web UI, RSS, дополнительные. Поиск работает по русской подписи и ключу API. Технический ключ доступен в подсказке, сложные списки раскрываются отдельно. «Сохранить» отправляет только изменённые значения после подтверждения; «Отменить изменения» восстанавливает исходные.

В нижней строке отображается свободное место для диска папки загрузки по умолчанию. Значение обновляется примерно раз в 3 секунды; другие серверные папки могут находиться на других дисках. Меньше 10 ГиБ — оранжевый, меньше 1 ГиБ — красный. Без данных показан прочерк. Версия qBittorrent доступна в подсказке подключения.

## Оформление и трей

«Вид → Тема оформления»: **Graphite Theme**, **White Theme**, **Marine Dark Theme**. Тема сохраняется. Дополнительный масштаб 80–150% задаётся в настройках приложения и также сохраняется; системный DPI учитывается автоматически.

Логотип — округлая монограмма **qbr**: qBit Remote. Буквы разделены, у `r` широкое плечо; палитра сине-бирюзовая. В боковой панели и About используется монограмма с полным названием. Надпись адаптируется к светлой и тёмной теме. Иконки окна, трея и приложения содержат только qbr на прозрачном фоне, без квадратной подложки. Значки файлов .torrent настраиваются отдельно.

Монограмма отрисовывается из геометрии под физический размер и DPI, текстуры кэшируются. В Windows EXE сохранён [признак отказа от автоматического оверлея RTSS](https://github.com/beeradmoore/RTSSHooksCompatibility-sample); принудительный ForceHooking может переопределить отказ.

Левый щелчок по трею скрывает/показывает окно, правый открывает меню. Двойной щелчок обрабатывается как одно переключение. Если трей недоступен, крестик закрывает окно обычным образом. Настройки сохраняются каждые 3 секунды и при штатном выходе.

## Сборка и обновление

Для Windows нужны Rust stable MSVC, Visual Studio Build Tools с поддержкой C++ и Windows SDK. Python 3 требуется для проверки целостности, пользователю готового EXE он не нужен.

```powershell
python scripts/check-project.py
cargo fmt --check
cargo test --locked --all-features
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo build --release --locked
```

Бинарник: `target/release/qbit-remote.exe`. Комплект поставки: `Release/qbit-remote.exe` и самостоятельная инструкция `Release/README.md`; `dist/qbit-remote.exe` содержит ту же сборку. Установщик, цифровая подпись и автообновление пока отсутствуют.

Перед заменой EXE штатно завершите приложение. Правила выпуска описаны в [AGENTS.md](AGENTS.md): версия повышается только при изменениях кода и синхронизируется в Cargo.toml/Cargo.lock/README/CHANGELOG; работа с документацией и скриншотами не повышает версию. При выпуске предыдущий EXE архивируется в `dist_backup` с проверкой SHA-256, бинарники dist и Release сверяются. Архивы не удаляются автоматически.

### CI и целостность

В `.github/workflows/windows.yml` выполняются проверка ресурсов, форматирование, тесты всех feature, clippy и release-сборка. `.github/workflows/macos.yml` готовит пакеты на runners `macos-15` и `macos-15-intel`. Оба workflow поддерживают push, pull request и ручной запуск.

`python scripts/check-project.py` проверяет наличие встроенных ресурсов и исходных изображений, CRC PNG, версии, локальные ссылки и LF в shell-скрипте. `--release` дополнительно проверяет SHA-256 dist/Release, состав поставки и PE-экспорт отказа от RTSS с нулевым DWORD. После восстановления из бекапа запускайте проверку до сборки.

Результаты последнего полного прогона, исторических нативных проверок и ограничения собраны в [docs/TESTING.md](docs/TESTING.md). [Аудит восстановления 0.2.77](docs/INTEGRITY.md) — исторический отчёт, а не описание текущего состояния репозитория.

### Скриншоты и бренд

`scripts/update-screenshots.ps1` сохраняет **23 снимка** на демонстрационных данных в `docs/screenshots/v<версия>/`. Для нового выпуска обновите ссылки на галерею в README. Сценарию нужен рабочий стол Windows. Ручной запуск — `cargo run --locked --features ui-smoke`. `QBIT_SMOKE_PAGE` выбирает страницу, `QBIT_SMOKE_THEME` — `graphite`, `white` или `marine`, `QBIT_SMOKE_ZOOM` — масштаб. Результат ручного запуска сохраняется в `dist/ui-smoke.png`, состояние — в отдельном `dist/ui-smoke-state.ron`.

Форму и цвета монограммы qbr задаёт `src/icon_pixels.rs`. Векторный исходник хранится в `assets/brand-monogram.svg`. В боковой панели и окне «О программе» короткая тень есть у монограммы и названия. Зазор между ними пропорционален ширине монограммы. Значки рабочего стола, окна и трея получают тень при растеризации. Экспорт PNG использует установленный Segoe UI Semibold (сам файл шрифта не распространяется). Для пересборки ресурсов:

```powershell
$env:QBIT_IMPORT_BRANDING='1'
cargo run --locked --features ui-smoke
Remove-Item Env:QBIT_IMPORT_BRANDING
```

Команда создаёт PNG/RGBA монограммы, размеры 512/32/16, [полную композицию](assets/brand-lockup.png) и [презентацию](assets/brand-presentation.png). Затем пересоберите приложение. Генерация использует код монограммы и не импортирует произвольную замену `logo-master.png`.

## Значок и ассоциации файлов Windows

В настройках приложения откройте «Значок и ассоциации файлов». Выберите один из шести объёмных значков: магнит, документ Torrent, синюю или зелёную стрелку, зелёную плитку или синий круг и нажмите «Применить значок и зарегистрировать ассоциации». Выбор значка показывает сами изображения; название появляется при наведении. По умолчанию выбран объёмный магнит. Применение обновляет также обработчик «Открыть с помощью» (Applications\qbit-remote.exe), если Windows использует его для .torrent.

## Автозапуск Windows

В окне «Подключение и настройки» включите «Запускать вместе с Windows», чтобы приложение запускалось после входа в систему. По умолчанию автозапуск отключён.
