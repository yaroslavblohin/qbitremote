# qBit Remote

Клиент на Rust для управления удалённым qBittorrent через Web UI API. Текущая версия — **0.2.17**, сборка — **только Windows**.

## Возможности

- Правый щелчок по выбранной строке сохраняет всю группу и открывает её контекстное меню; щелчок по другой строке выбирает только её. Команды сгруппированы по назначению, снабжены пиктограммами; активные режимы отмечены галочкой. На небольшом экране меню прокручивается.
- «Вид → Тема оформления»: **Marine LLM Theme** — исходная морская палитра; **Graphite Theme** — спокойная тёмная тема с нейтральными серыми поверхностями и насыщенными цветными акцентами. Переключение без перезапуска, выбор сохраняется. По умолчанию используется Graphite Theme; сохранённый выбор темы имеет приоритет. **White Theme** — мягкая светлая тема со светло-серыми поверхностями и сдержанными акцентами.
- GUI на egui/eframe с тёмными и светлой темами: боковые фильтры, сортируемая таблица, поиск, сведения о выбранном торренте.
- Меню «Файл», «Правка», «Вид», «Серверы», «Справка». Настройки приложения — в «Правка → Настройки приложения», параметры qBittorrent — в «Серверы → Настройки qBittorrent», масштаб — в «Вид». «Файл → Выход» завершает приложение, включая режим сворачивания в трей.
- «Вид → Колонки»: 38 колонок списка qBittorrent, включение чекбоксами, «Все» и «По умолчанию». Выбор, порядок, ширина и сортировка сохраняются; для большого набора доступна горизонтальная прокрутка. Щелчок по заголовку сортирует по значению, перетаскивание меняет порядок. Поля, которые версия Web API не возвращает, отображаются как «—».
- Подключение к qBittorrent 4.1+ / 5.x, cookie-сессия, обновление каждые 3 секунды. Запросы выполняются вне потока GUI.
- Именованные профили серверов с отдельными зашифрованными паролями. Переключение — в меню «Серверы»; одновременно активен один сервер. Добавление, изменение, сохранение и удаление профилей — в «Серверы → Управление серверами». Поля доступны для редактирования и при подключении: изменение адреса, логина или пароля отключает текущий сервер, название можно менять без отключения. После изменения учётных данных нажмите «Сохранить профиль» и «Подключиться».
- Автоподключение к последнему выбранному профилю при запуске включено по умолчанию и отключается в настройках. Старое сохранённое подключение автоматически становится первым профилем. Если пароль не сохраняется, для входа может потребоваться ввести его снова.
- Высота панели информации о торренте изменяется перетаскиванием верхней границы и сохраняется. Пустые вкладки и загрузка данных не меняют её размер; длинное содержимое прокручивается внутри панели.
- Запуск, остановка, добавление magnet/HTTP-ссылок и `.torrent`-файлов. Путь сохранения относится к серверу.
- Удаление с подтверждением; удаление файлов на сервере по умолчанию выключено.
- Подробности торрента: свойства, трекеры, пиры, HTTP-источники, файлы с приоритетами и переименованием, карта частей, график скорости. Команды перепроверки, анонса, очереди, последовательной загрузки, принудительного запуска, автоуправления, категорий и тегов, переноса данных на сервере, ограничений раздачи и экспорта `.torrent`.
- Лимиты скачивания и отдачи — глобальные, для одного торрента или выделенной группы. Ввод в КиБ/с, 0 снимает ограничение. Переключение альтернативного режима; расписание и альтернативные значения — в настройках сервера.
- Поиск через серверные плагины: результаты, страницы, остановка, удаление поиска, установка/обновление/включение плагинов. Загрузка результата через движок поиска, если сервер возвращает его имя.
- RSS: папки, ленты, статьи, прочтение, перемещение, обновление, URL и интервал; создание, редактирование, копирование, переименование, удаление правил и просмотр подходящих статей; импорт и экспорт правил в JSON с проверкой файла и выбором замены совпадений.
- Основной журнал и журнал пиров с фильтром; управление категориями и тегами; редактор параметров, возвращённых `app/preferences`, с отправкой только изменённых значений.
- Расширенные панели загружаются по мере открытия и обновляются раз в 5 секунд. Функции зависят от версии и конфигурации сервера; ошибки API показываются в интерфейсе. Полное совпадение со всеми версиями настольного qBittorrent не заявляется: расширенные параметры пока используют имена API.
- Клиент не открывает папки и загруженные файлы удалённого сервера в локальном проводнике, не запускает серверные программы и не требует сетевых дисков. Управление файлами торрентов выполняет сам сервер через API.
- Windows tray: двойной щелчок открывает окно; меню содержит «Открыть» и «Выход». Крестик по умолчанию скрывает окно в трей. Если трей создать не удалось, окно закрывается обычным образом.
- В одной сессии Windows работает только один экземпляр приложения. Повторный запуск сразу завершается, в том числе когда первое окно скрыто в трее. После выхода или аварийного завершения блокировка снимается автоматически.
- Вкладка «Файлы» показывает дерево раскрываемых папок вместо полных путей в каждой строке. Доступны поиск по имени или пути, «Развернуть всё» и «Свернуть всё».
- Системный HiDPI через winit/egui и дополнительный масштаб 80–150% в настройках.
- Сохраняются адрес, имя пользователя, масштаб, настройка трея и геометрия окна. После успешного входа пароль сохраняется зашифрованным через Windows DPAPI для текущей учётной записи Windows. Сохранённый пароль привязан к адресу сервера и имени пользователя. Cookie остаются только в памяти.
- Флажок «Сохранять пароль на этом компьютере» включён по умолчанию. Если снять его, сохранённый пароль удаляется из настроек при ближайшем сохранении. Настройки автоматически сохраняются каждые 3 секунды и при штатном выходе.

## Управление торрентами и файлами

| Действие | Как выполнить |
| --- | --- |
| Выбрать торрент | Щёлкнуть по любой части строки, включая название и прогресс. |
| Выбрать несколько | Ctrl+щелчок добавляет или снимает строку; Shift выбирает диапазон в текущем порядке сортировки; Ctrl+Shift добавляет диапазон. |
| Выбрать все / снять выбор | Ctrl+A выбирает весь видимый после фильтрации список (включая строки за пределами экрана); Escape снимает выделение. В текстовых полях Ctrl+A работает с текстом. |
| Выполнить групповую команду | Запуск, остановка и удаление — на панели, в «Правка» и контекстном меню. Остальные групповые операции и лимиты скорости — в контекстном меню. |
| Открыть команды торрента | Нажать правую кнопку мыши на его строке. Команды относятся к выделенной группе; щелчок по невыбранной строке выбирает только её. |
| Отсортировать список | Щёлкнуть по ячейке заголовка; повторный щелчок меняет направление. |
| Настроить колонки | «Вид → Колонки»; порядок меняется перетаскиванием заголовков, ширина — перетаскиванием их границ. |
| Изменить высоту сведений | Перетащить верхнюю границу нижней панели. Высота сохраняется при смене вкладок и перезапуске. |
| Раскрыть или свернуть папку | Нажать стрелку рядом с названием во вкладке «Файлы». |
| Переименовать папку | Дважды щёлкнуть по названию либо выбрать «Переименовать папку…» в контекстном меню папки. |
| Переименовать файл | Нажать «Имя…» в строке файла. |
| Изменить приоритет файла | Выбрать значение в списке приоритетов его строки. |

При смене сервера выделение очищается. Торренты, скрытые фильтром или удалённые на сервере, исключаются из выбора. Перед групповым удалением показываются количество и названия. Панель сведений относится к последнему выбранному торренту; переименование и экспорт доступны при выборе одного торрента.

Контекстное меню торрента компактное, с пиктограммами и группами команд: проверка и трекеры, очередь, режим загрузки, управление и раздача, данные и организация, ограничения и экспорт. Длинное меню прокручивается. Кнопки «Действия» в панели сведений больше нет.

При переименовании папки форма автоматически получает её текущий относительный путь. Укажите новый путь и подтвердите изменение: операция выполняется на сервере. Отдельных кнопок переименования папок нет. Поиск по имени или пути показывает подходящие файлы с раскрытыми родительскими папками; доступны «Развернуть всё» и «Свернуть всё».

## Импорт и экспорт правил RSS

Откройте «RSS → Правила автозагрузки». «Экспорт правил…» сохраняет свежий список всех правил сервера в `rss-downloader-rules.json`. Файл совместим с JSON-экспортом qBittorrent и включает имена, фильтры, URL лент и параметры торрентов.

«Импорт правил…» принимает JSON (UTF-8, до 8 МиБ), проверяет его и показывает список имён до отправки. Совпадающие имена по умолчанию пропускаются; флажок замены разрешает перезаписать их. Правила, отсутствующие в файле, не удаляются. Ленты не создаются автоматически: добавьте нужные URL на целевом сервере. Пути сохранения остаются серверными и переносятся без изменений. Включённые правила могут сразу начать загрузки.

После выполнения отображается число сохранённых и пропущенных правил. При ошибке импорт останавливается с частичным результатом: уже сохранённые правила не откатываются. Старый бинарный формат `.rss` не поддерживается — экспортируйте правила из qBittorrent в JSON.

## Оформление

Темы выбираются в «Вид → Тема оформления» и применяются без перезапуска:

- **Graphite Theme** — тема по умолчанию: графитовые поверхности и насыщенные цветные акценты.
- **Marine LLM Theme** — тёмная сине-морская палитра с бирюзовым акцентом.
- **White Theme** — мягкие светло-серые поверхности, менее резкий текст и сдержанные акценты.

Сохранённый выбор имеет приоритет над темой по умолчанию. Масштаб 80–150% настраивается в «Вид → Масштаб интерфейса» поверх системного DPI.

## Запуск и сборка

Нужны Rust stable (MSVC), Visual Studio Build Tools с workload C++ и Windows SDK.

```powershell
cargo run --locked
cargo test --locked
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo build --locked --release
```

Исполняемый файл: `target/release/qbit-remote.exe`. Для распространения достаточно этого EXE. Пока нет установщика, подписи и автообновления.

Готовая локальная сборка: `dist/qbit-remote.exe`. Для обновления выберите «Файл → Выход» (крестик обычно скрывает окно в трей), замените EXE и запустите его снова. Настройки сохраняются отдельно от исполняемого файла.

Папка `Release/` содержит готовый комплект для распространения: актуальный `qbit-remote.exe` и самостоятельный `README.md` с инструкциями. Оба файла обновляются при каждом выпуске.

При каждом наборе изменений версия повышается. Перед заменой готового EXE предыдущая сборка архивируется в `dist_backup/` с версией и датой в имени; архивы исключены из Git. В `dist/` остаётся только актуальный EXE. Правила выпуска закреплены в [AGENTS.md](AGENTS.md).

## Подключение

1. В qBittorrent включите Web UI и задайте учётные данные.
2. Откройте «Серверы → Управление серверами» в клиенте.
3. Укажите адрес вроде `https://seedbox.example.org` или `http://192.168.1.10:8080`. Поддерживается путь reverse proxy, например `https://example.org/qbit/`.
4. Введите логин, пароль и нажмите «Подключиться».

Проверка TLS включена. Самоподписанные сертификаты без доверенной цепочки не принимаются. HTTP передаёт учётные данные без шифрования; для удалённого доступа используйте HTTPS или доверенный VPN. Перенаправления не выполняются: указывайте конечный адрес Web UI. При потере связи клиент покажет ошибку и предложит повторное подключение.

## Структура

- `src/app.rs` — интерфейс и состояние окна.
- `src/api.rs` — HTTP API, авторизация, фоновый поток и тесты локального HTTP-сервера.
- `src/model.rs` — модели и форматирование.
- `src/columns.rs` — каталог колонок, сортировка, порядок и ширина.
- `src/icon.rs`, `src/icon_pixels.rs` — общий рисунок иконки окна, трея и EXE.
- `build.rs` — создание многоразмерной ICO и встраивание ресурса в EXE через Windows SDK (`rc.exe`). При нестандартной установке путь к компилятору можно задать переменной `RC`.
- `src/theme.rs` — темы, палитры и оформление виджетов.
- `src/single_instance.rs` — защита от повторного запуска через именованный Windows mutex.
- `src/tray.rs` — Windows tray, изолированный от сетевого слоя.
- `src/credentials.rs` — шифрование пароля Windows DPAPI и привязка к серверу/пользователю.
- `src/remote.rs`, `src/remote/pages.rs` — подробности торрентов, удалённые разделы, формы, кэш запросов и обработка ответов.
- `src/remote/file_tree.rs` — дерево файлов, раскрытие папок и поиск.

## Проверки

UI-тесты проверяют выбор торрента и открытие контекстного меню правой кнопкой, а также оба способа переименования папки без её сворачивания. Тесты тем проверяют восстановление сохранённого выбора и Graphite по умолчанию.

Автоматические тесты проверяют URL reverse proxy, отклонение некорректных адресов, cookie-авторизацию, кодирование пароля, команды для API 4.x/5.x, отказ входа и HTTP-ошибки. Тесты не обращаются к реальному серверу.

Проверяются также сохранение колонок и сортировки, выбор строки по тексту, щелчок и перетаскивание заголовков, стабильная высота панели сведений, дерево файлов, ответы добавления торрента в старом и новом формате API. Межпроцессный тест проверяет запрет второго экземпляра и возможность повторного запуска после освобождения блокировки.

Дополнительные тесты проверяют успешный HTTP 204 в qBittorrent 5.2, восстановление зашифрованного пароля после сериализации настроек, отсутствие открытого пароля в настройках, изоляцию учётных записей/серверов, отказ от сохранения, повреждение шифротекста и загрузку старых настроек. `live_server_read_only` исключён из обычного запуска; для него требуются явно заданные `QBIT_TEST_ADDRESS`, `QBIT_TEST_USERNAME`, `QBIT_TEST_PASSWORD`.

Для приёмки на рабочем сервере: подключение, добавление разрешённого тестового торрента, остановка/запуск, удаление без файлов, потеря связи; перенос окна между мониторами с DPI 100/150/200%; закрытие в трей, восстановление двойным щелчком, выход через меню.

`cargo run --features ui-smoke` открывает тестовое окно с явно обозначенными фиктивными данными, проверяет создание трея, сохраняет `dist/ui-smoke.png` и завершает приложение. Этот режим не входит в обычную сборку и не подключается к серверу. Переменная окружения `QBIT_SMOKE_ZOOM=1.5` позволяет проверить увеличенный масштаб.

Параметры демонстрационного режима:

| Переменная | Значения |
| --- | --- |
| `QBIT_SMOKE_THEME` | `graphite` (по умолчанию), `marine`, `white` |
| `QBIT_SMOKE_PAGE` | `torrents`, `files`, `speed`, `settings`, `actions` (правый щелчок по тестовому торренту) |
| `QBIT_SMOKE_ZOOM` | Масштаб, например `1` или `1.5` |
| `QBIT_SMOKE_COLUMNS` | Любое заданное значение включает все колонки |

Для обновления снимков в документации запустите `./scripts/update-screenshots.ps1`. Скрипт собирает тестовый режим и сохраняет восемь снимков: список, файлы, скорость, Graphite, White, групповое меню, множественный выбор и импорт RSS в `docs/screenshots/`. Требуется рабочий стол Windows; пользовательские настройки и сервер не используются.

`QBIT_SMOKE_TRAY=hidden` включает нативную проверку: 10 циклов закрытия в трей/восстановления и выход из скрытого окна. Значения `visible` и `minimized` проверяют выход из открытого и свёрнутого окна. Используются те же обработчики восстановления и выхода, что и в меню трея, без кликов мышью. Тестовые окна используют отдельный файл состояния `dist/ui-smoke-state.ron`.

Все три сценария с ограничением времени выполняет `./scripts/test-tray.ps1` (нужен доступный рабочий стол Windows). Скрипт проверяет штатное завершение процесса, а при зависании завершает только свой тестовый процесс и сообщает ошибку.

Документация: [qBittorrent Web API](https://github.com/qbittorrent/qBittorrent/wiki/WebUI-API-(qBittorrent-5.0)), [eframe](https://docs.rs/eframe/0.31.1/eframe/), [tray-icon](https://docs.rs/tray-icon/0.20.1/tray_icon/).

Расширенные операции сверены с контроллерами `src/webui/api` и панелями свойств официального qBittorrent, ревизия `a87f8f9c282e7341b1f4f9e9a5a66c869d2366a6`. Реализация GUI на Rust самостоятельная. Локальная исследовательская копия `.reference/` исключена из поставки.

Тесты расширений проверяют единицы и границы скорости, реальные HTTP-запросы лимитов на mock-сервере, ошибки 404/отклонение команд, IPv6-адреса, отбрасывание ответов старой сессии, объединение повторных запросов и сохранение правок при отказе API. Read-only интеграционный тест дополнительно читает 18 расширенных API-разделов. `QBIT_SMOKE_PAGE=speed` и `settings` выбирают тестовую страницу для снимка интерфейса.


Контекстное меню использует одинаковый размер шрифта и высоту команд. Группы обозначены приглушёнными заголовками без горизонтальных разделителей; всё меню прокручивается целиком.
