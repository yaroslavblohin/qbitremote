# qBit Remote

Клиент на Rust для управления **удалённым qBittorrent** через Web UI API. Текущая версия — **0.2.89**. Проверенная готовая сборка — **Windows**; порт macOS остаётся экспериментальным и требует нативной проверки.

[История изменений](CHANGELOG.md) · [Проверки](docs/TESTING.md) · [Аудит целостности](docs/INTEGRITY.md) · [macOS](docs/MACOS.md)

## Быстрый запуск

1. Запустите `Release/qbit-remote.exe`. Установка не требуется; инструкция для пользователя находится в [Release/README.md](Release/README.md).
2. Включите Web UI на сервере qBittorrent и разрешите доступ с компьютера клиента.
3. Создайте профиль подключения: адрес, имя пользователя и пароль. Поддерживаются адреса вида `https://seedbox.example.org` и пути reverse proxy, например `https://example.org/qbit/`.
4. Нажмите «Подключиться». Список торрентов обновляется автоматически; ручное обновление доступно через «Файл → Обновить список».

Автоподключение и сохранение пароля включены по умолчанию. В Windows пароль защищён DPAPI текущей учётной записи и привязан к адресу сервера и имени пользователя. Cookie хранятся только в памяти. Для удалённого доступа используйте HTTPS или доверенный VPN: HTTP не шифрует учётные данные.

Крестик окна по умолчанию скрывает приложение в трей. Для завершения работы выберите «Файл → Выход» или «Выход» в меню трея.

## Возможности

- Профили серверов, автоподключение, зашифрованное сохранение пароля в Windows.
- Поиск, фильтры, сортировка, настройка видимости, ширины и порядка колонок; множественное выделение и групповые команды.
- Добавление `.torrent`, magnet/HTTP-ссылок, результатов серверного поиска и статей RSS через диалог выбора файлов.
- Запуск, остановка, удаление с подтверждением, перепроверка, обновление анонса, очередь, принудительный запуск, последовательная загрузка и приоритет крайних частей.
- Файлы и папки деревом, приоритеты, переименование на сервере, открытие локально доступных данных через сопоставления путей.
- Свойства торрента, карта частей, пиры, трекеры, HTTP-источники и индивидуальный график скорости.
- Категории и теги, комментарии, перенос данных на сервере, ограничения раздачи, экспорт `.torrent` и копирование magnet.
- Глобальные и индивидуальные лимиты скачивания/отдачи, альтернативный режим скорости.
- Серверный поиск и управление поисковыми плагинами; RSS-ленты, статьи, правила автоматической загрузки, импорт/экспорт правил JSON.
- Основной журнал и журнал пиров, компактный редактор настроек удалённого qBittorrent с отправкой только изменённых значений.
- Трей, три темы, системный HiDPI и дополнительный масштаб интерфейса 80–150%.

Функции зависят от версии и конфигурации сервера. Поддерживаются различия команд API qBittorrent 4.x/5.x; полное совпадение со всеми версиями настольного qBittorrent не заявляется. Клиент не предоставляет локальные функции сервера и не монтирует сетевые ресурсы самостоятельно.

## Управление торрентами

Панель после поиска содержит кнопки: **добавить → запустить → остановить → удалить → выше в очереди → ниже в очереди**. Кнопки квадратные, с подсказками; добавление доступно без выделенного торрента. Стрелка вверх — фиолетовая, вниз — бордовая.

Счётчик рядом с заголовком показывает число видимых торрентов с учётом раздела и поиска. Счётчики боковой панели показывают общее количество в каждом разделе независимо от поиска. Числа оформлены тем же шрифтом, что и соответствующие подписи. Цвет счётчика заголовка совпадает со счётчиком выбранного раздела в боковой панели. Загрузка обозначается синим цветом: стрелка, счётчики, состояние и прогресс используют общий оттенок темы.

Щелчок выбирает торрент, Ctrl добавляет или исключает его из выбора, Shift выделяет диапазон, Ctrl+A выбирает все видимые строки. Количество выбранных показано в нижней строке состояния. При смене сервера выделение очищается; скрытые фильтром и удалённые торренты исключаются из выбора.

Панель сведений относится к последнему выбранному торренту. Её высота изменяется перетаскиванием верхней границы и сохраняется. Крестик справа или Esc скрывает панель и снимает выделение. Вкладки: «Общее», «Файлы», «Части», «Пиры», «Трекеры», «График», «HTTP-источники».

Ссылки в полях «Комментарий», «Magnet-ссылка» (`magnet_uri`) и «Трекер» (`tracker`) кликабельны, включая переносы строк. HTTP/HTTPS открываются в браузере по умолчанию; magnet и UDP — через системный обработчик соответствующей схемы, если он установлен. Правый щелчок открывает меню копирования точного адреса, открытия и отмены.

«Дополнительные сведения» показывают только поля, отсутствующие в основной таблице. Повторы удаляются по смыслу API-ключей, включая `comment`, даты, объёмы передачи, время активности и приватность. Основные свойства имеют приоритет; null дополняется доступным значением из списка торрентов. Одинаковые значения разных величин не считаются дублями.

Меню «Вид → Колонки» содержит выбор полей и кнопки «Все»/«По умолчанию»; лишняя строка под прокруткой удалена.

Правый щелчок открывает общее прокручиваемое меню. Команды запуска, остановки, очереди, удаления и лимитов доступны для группы; переименование торрента и экспорт — для одного выбранного торрента. Удаление требует подтверждения, флажок удаления файлов на сервере по умолчанию выключен.

Для перемещения в очереди она должна быть включена на сервере. Клиент сравнивает позиции до и после команды: последний торрент ниже не перемещается, а завершённые раздачи с прочерком в колонке очереди не считаются следующими позициями очереди загрузки.

Состояние раздачи без активной передачи отображается как **«Ожидание» бирюзовым текстом**. Полоса завершённого торрента остаётся зелёной. Готовые части в карте также зелёные. В списке пиров показаны флаги стран, для неизвестной страны — «Весёлый Роджер».

Сообщения операций и ошибки сохраняются в отдельной **«Консоли приложения»**, закрытой по умолчанию: «Вид → Консоль приложения…» или одноимённый пункт контекстного меню торрента. Доступны очистка и копирование последних 300 записей. Это журнал клиента, а не командная оболочка сервера.

## Добавление и выбор файлов

В Windows назначьте `qbit-remote.exe` обработчиком `.torrent` через «Открыть с помощью». При повторном запуске файл передаётся уже работающему экземпляру и окно восстанавливается из трея. Поддерживаются несколько файлов, пробелы и кириллица. Сохраняйте путь к EXE при обновлениях, чтобы ассоциация продолжала работать.

До подтверждения диалога сервер получает только метаданные, содержимое не скачивается. Для magnet/HTTP-ссылки получение списка файлов может занять время. Несколько торрентов обрабатываются по очереди; отмена или закрытие диалога до подтверждения не добавляет торрент.

- Выберите файлы или папки в дереве, при необходимости задайте серверную папку, категорию и теги.
- Флажок папки меняет выбор всех вложенных файлов, включая скрытые поиском и свёрнутые. Поиск не меняет уже выбранные файлы.
- Приоритеты: «Не скачивать», «Обычный», «Высокий», «Максимальный». Приоритет папки применяется ко всем потомкам, «Разный» обозначает смешанное состояние.
- Кнопки и пункты списка приоритетов центрированы; ширина кнопки фиксирована. Обычный приоритет зелёный, высокий оранжевый, максимальный красный, пропуск и смешанный — приглушённые.
- Нижняя строка показывает количество и размер выбранных файлов. Без выбранных файлов добавление недоступно.

**«Начать загрузку после добавления» включён по умолчанию.** Загрузка начинается после нажатия «Добавить торрент». Снимите флажок для добавления в остановленном состоянии. Выбор файлов, приоритеты и состояние запуска передаются серверу одним запросом. Автоматические правила RSS используют собственные параметры и не открывают этот диалог.

## Открытие файлов через сопоставления

Подключите серверный ресурс в Windows и задайте правила в профиле подключения либо в «Серверы → Настройки qBittorrent → Сопоставление папок сервера с этим компьютером».

| На сервере | На клиенте Windows |
| --- | --- |
| `/downloads/complete` | `Y:\torrents\complete` |
| `/downloads` | `\\NAS\Downloads` |

Папка должна уже открываться в Проводнике. Клиент не скачивает файлы через Web UI API. Правила сохраняются автоматически отдельно для каждого профиля; «Обзор…» выбирает папку на компьютере.

В дереве файлов доступны двойной щелчок и команды «Открыть файл», «Открыть папку», «Открыть содержащую папку». Жёлтая кнопка рядом с поиском открывает сопоставленную папку загрузки. Щелчок по значку папки раскрывает дерево; переименование выполняется на сервере через контекстное меню. Команды открытия доступны и из списка торрентов; для многoфайлового торрента можно выбрать файл в папке.

Выбирается самое длинное совпадение по целым компонентам серверного пути; регистр Unix учитывается, Windows — нет. Корневая папка уже входит в имя файла API и повторно не добавляется. Недоступный ресурс, отсутствующий файл и отсутствие правила записываются как ошибки в консоль; успешное открытие не создаёт плашку над таблицей. Частично загруженный файл открывается только по существующему имени.

## Скорость и графики

Лимиты задаются глобально, для одного торрента или выделенной группы. Ввод — в КиБ/с, **0 снимает ограничение**. Альтернативный режим переключается отдельно; расписание и альтернативные значения задаются в настройках сервера.

При каждом запуске запись всех графиков **выключена**. У каждого торрента собственный чекбокс записи, история и масштаб. Общий график включается отдельно и не включает индивидуальные. При включённой записи данные собираются из фонового опроса примерно раз в 3 секунды независимо от вкладки, открытой панели и работы в трее. При выключенных графиках история не собирается.

Доступны координатная сетка, диапазон времени, масштаб времени/скорости, сброс и переход к концу. Колесо мыши меняет масштаб времени, Ctrl+колесо — скорости, перетаскивание перемещает видимый диапазон. История хранится в памяти с момента включения записи. Выключение освобождает её; отключение, смена сервера и завершение приложения очищают историю.

На снимках показан синтетический пример четырёх минут уже идущей загрузки: почти ровная скорость скачивания, небольшие колебания и независимые просадки отдачи. В начале записи уже получено около 14% торрента, в конце — 64%. Размер, объёмы и последние значения графиков согласованы с таблицей и статистикой. Общий график дополнительно учитывает торрент, который был полностью скачан до начала записи.

В BitTorrent можно одновременно скачивать новые части и отдавать уже полученные и проверенные. Поэтому зелёная линия у незавершённого торрента допустима: речь не об отдаче ещё отсутствующих данных. Это предусмотрено [спецификацией BitTorrent (BEP 3)](https://www.bittorrent.org/beps/bep_0003.html#peer-protocol).

## RSS и настройки сервера

«Импорт правил…» принимает JSON UTF-8 до 8 МиБ и показывает предпросмотр перед отправкой. Совпадающие имена по умолчанию пропускаются; флажок замены разрешает перезапись. Другие правила не удаляются, ленты не создаются автоматически. «Экспорт правил…» сохраняет правила в JSON. Пути в правилах относятся к серверу; включённые правила могут сразу начать загрузки.

Настройки сервера сгруппированы по разделам: загрузки, скорость, соединение, BitTorrent, очередь и раздача, Web UI, RSS, дополнительные. Поиск работает по русской подписи и ключу API. Технический ключ доступен в подсказке, сложные списки раскрываются отдельно. «Сохранить» отправляет только изменённые значения после подтверждения; «Отменить изменения» восстанавливает исходные.

В нижней строке отображается свободное место для диска папки загрузки по умолчанию. Значение обновляется примерно раз в 3 секунды; другие серверные папки могут находиться на других дисках. Меньше 10 ГиБ — оранжевый, меньше 1 ГиБ — красный. Без данных показан прочерк. Версия qBittorrent доступна в подсказке подключения.

## Оформление и трей

«Вид → Тема оформления»: **Graphite Theme**, **White Theme**, **Marine Dark Theme**. Тема сохраняется. Дополнительный масштаб 80–150% задаётся в настройках приложения и также сохраняется; системный DPI учитывается автоматически.

Логотип выполнен в стиле Amiga demoscene: монограмма **qb** и вплотную к ней **it Remote** в одну строку. b строится поворотом q на 180° с общим наклоном; корпуса разделены тонкой гранью, стрелки остаются целыми. У монограммы бирюзово-фиолетовый градиент, у надписи — серебристо-голубой и синий. Тёмная обводка сохраняет читаемость на светлой теме. В About используется актуальная композиция на лесном фоне, в маленьких иконках — только qb.

Левый щелчок по трею скрывает/показывает окно, правый открывает меню. Двойной щелчок обрабатывается как одно переключение. Если трей недоступен, крестик закрывает окно обычным образом. Настройки сохраняются каждые 3 секунды и при штатном выходе.

## Сборка и обновление

Для Windows нужны Rust stable MSVC, Visual Studio Build Tools с поддержкой C++ и Windows SDK. Python 3 требуется для проверки целостности, пользователю готового EXE он не нужен.

```powershell
python scripts/check-project.py
cargo fmt --check
cargo test --locked --all-features
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo build --release --locked
```

Бинарник: `target/release/qbit-remote.exe`. Комплект поставки: `Release/qbit-remote.exe` и самостоятельная инструкция `Release/README.md`; `dist/qbit-remote.exe` содержит ту же сборку. Установщик, цифровая подпись и автообновление пока отсутствуют.

Перед заменой EXE штатно завершите приложение. Правила выпуска описаны в [AGENTS.md](AGENTS.md): версия синхронизируется в Cargo.toml/Cargo.lock/README/CHANGELOG, предыдущий EXE архивируется в `dist_backup` с проверкой SHA-256, бинарники dist и Release сверяются. Архивы не удаляются автоматически.

### CI и целостность

В `.github/workflows/windows.yml` выполняются проверка ресурсов, форматирование, тесты всех feature, clippy и release-сборка. `.github/workflows/macos.yml` готовит пакеты на runners `macos-15` и `macos-15-intel`. Оба workflow поддерживают push, pull request и ручной запуск.

`python scripts/check-project.py` проверяет наличие встроенных ресурсов и исходных изображений, CRC PNG, версии, локальные ссылки и LF в shell-скрипте. `--release` дополнительно проверяет SHA-256 dist/Release и состав поставки. После восстановления из бекапа запускайте проверку до сборки.

Последний полный прогон на Windows, выпуск **0.2.89**: **117 тестов прошли, 6 исключены**, форматирование и clippy без замечаний, release-сборка успешна. Ресурсы бренда повторно сгенерированы с совпадением SHA-256; нативный UI-smoke About завершился штатно. ### Скриншоты и бренд

`scripts/update-screenshots.ps1` обновляет все **22 снимка** на демонстрационных данных без подключения к серверу; нужен рабочий стол Windows. Ручной запуск: `cargo run --locked --features ui-smoke`. `QBIT_SMOKE_PAGE` выбирает страницу, `QBIT_SMOKE_THEME` — `graphite`, `white` или `marine`, `QBIT_SMOKE_ZOOM` — масштаб. Результат ручного запуска сохраняется в `dist/ui-smoke.png`, состояние — в отдельном `dist/ui-smoke-state.ron`.

Монограмма задаётся кодом `src/icon_pixels.rs`, надпись — `assets/brand-suffix.png`, лесной фон — `assets/brand-forest.png`. Для пересборки ресурсов:

```powershell
$env:QBIT_IMPORT_BRANDING='1'
cargo run --locked --features ui-smoke
Remove-Item Env:QBIT_IMPORT_BRANDING
```

Команда создаёт PNG/RGBA монограммы, размеры 512/32/16, [полную композицию](assets/brand-lockup.png) и [презентацию About](assets/brand-presentation.png). Затем пересоберите приложение. Генерация использует код монограммы и не импортирует произвольную замену `logo-master.png`.

## macOS

Экспериментальные реализации включают Keychain, значок строки меню, открытие доступных файлов и сопоставления `/Volumes/...`. Скрипт `scripts/build-macos.sh` готовит `.app` и ZIP для архитектуры текущего Mac с ad-hoc подписью.

**Нативная сборка и запуск macOS, а также запуск GitHub Actions в этой сессии не подтверждены.** Finder Open With/Apple Events, передача файлов уже запущенному экземпляру, системные NSWorkspace-пиктограммы и notarization ещё не реализованы. Инструкции и ограничения: [docs/MACOS.md](docs/MACOS.md).
