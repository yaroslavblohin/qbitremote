# qBit Remote 0.2.54

Клиент для управления удалённым qBittorrent через Web UI API. Только Windows. Установка не требуется: запустите `qbit-remote.exe` из этой папки.

## Подключение

1. В настройках qBittorrent на сервере включите Web UI и задайте имя пользователя и пароль.
2. В клиенте откройте «Серверы → Управление серверами».
3. Укажите название профиля, адрес Web UI (например, `http://192.168.1.10:8080`), логин и пароль.
4. Нажмите «Подключиться». Для нескольких серверов создайте отдельные профили; одновременно активен один сервер.

Автоподключение к выбранному профилю включено по умолчанию. Пароль при сохранении защищается Windows DPAPI и привязывается к текущей учётной записи Windows. Для удалённого доступа используйте HTTPS или доверенный VPN; HTTP не шифрует учётные данные.

## Открытие файлов через сопоставление папок

В дереве используются закрытые и открытые папки вместо стрелок. Файлы получают системные пиктограммы Windows по расширению и установленным ассоциациям; для неизвестного типа отображается стандартный значок. Это оформление применяется и в диалоге добавления торрента. Значки типов загружаются в фоне и кэшируются с учётом масштаба; доступ к содержимому файлов сервера для этого не нужен.

В «Серверы → Настройки qBittorrent» раскройте «Сопоставление папок сервера с этим компьютером». Этот же раздел доступен в настройках подключения. Нажмите «Добавить сопоставление» и укажите абсолютные пути:

| На сервере | На клиенте Windows |
| --- | --- |
| `/downloads` | `Z:\Downloads` |
| `/media` | `\NAS\Media` |

Папка на клиенте должна уже быть доступна через Проводник Windows. Приложение не монтирует ресурсы и не скачивает файл через Web UI API. Правила сохраняются автоматически в профиле выбранного сервера; смена профиля меняет набор правил. Кнопка «Обзор…» позволяет выбрать папку на компьютере.

Во вкладке «Файлы» нажмите правой кнопкой на строку и выберите «Открыть файл», «Открыть папку» или «Открыть содержащую папку». Двойной щелчок по файлу открывает его в приложении Windows по умолчанию. Компактная кнопка с жёлтой открытой папкой и листами внутри рядом с поиском открывает сопоставленный путь сохранения торрента; при наведении показано «Открыть папку загрузки». Двойной щелчок по папке открывает её в Проводнике; щелчок по значку папки раскрывает ветку дерева, а переименование остаётся в контекстном меню.

Например, при пути сохранения `/downloads` и файле `Фильм/video.mkv` первое правило открывает `Z:\Downloads\Фильм\video.mkv`. Корневая папка торрента уже входит в имя файла из API и повторно не добавляется. Если подходят несколько правил, выбирается самое длинное совпадение по целым компонентам пути; при одинаковых путях — первое правило. Для серверных путей Unix регистр учитывается, для путей Windows — нет.

В контекстном меню основного списка торрентов также доступны «Открыть папку» и «Открыть файл». Для одиночного файла открывается сам файл или содержащая его папка. Для торрента с папкой команда «Открыть файл» показывает выбор файла в этой папке. Используется фактический путь содержимого от сервера, а не отображаемое имя торрента. Если сервер не передаёт путь содержимого, используется папка сохранения. При выборе нескольких торрентов эти две команды недоступны; выберите один торрент. Отмена выбора файла не считается ошибкой.

Открытие файла или папки и отмена выбора выполняются без информационной плашки над списком торрентов. Отсутствие сопоставления, недоступная папка или отсутствующий файл показываются как ошибка. Запуск Проводника и ассоциаций Windows дожидается завершения передачи запроса Shell перед выходом фонового потока; ошибки запуска содержат полный путь и системное описание. Обращение к сетевому ресурсу и открытие выполняются в фоне. Для частично загруженного файла открывается только существующий путь; временные имена клиента qBittorrent автоматически не подбираются. Приоритеты и переименование по-прежнему изменяются на сервере через API.


## Основные возможности

- Правый щелчок по торренту открывает сгруппированное меню действий с пиктограммами. Команды применяются к выделенной группе; правый щелчок по невыбранной строке выбирает только её. Отдельной кнопки «Действия» в панели сведений нет.
- Поиск, сортировка, добавление ссылок и `.torrent`-файлов, запуск, остановка и удаление торрентов.
- 38 настраиваемых колонок через «Вид → Колонки». Видимость, порядок, ширина и сортировка сохраняются. Заголовки можно перетаскивать.
- Сведения о торренте, дерево файлов с раскрываемыми папками, приоритеты файлов, трекеры, пиры, графики и лимиты скорости.
- Темы «Graphite Theme» (по умолчанию), «Marine Dark Theme» и светлая «White Theme» через «Вид → Тема оформления». Выбор сохраняется.
- Настройки приложения — «Правка → Настройки приложения», настройки сервера — «Серверы → Настройки qBittorrent».
- Поиск через серверные плагины, RSS, журнал, категории и теги. Доступность зависит от версии и конфигурации сервера.

Пути загрузки и операции с файлами относятся к удалённому серверу. Удаление данных на сервере по умолчанию выключено и требует отдельного выбора.

## Открытие .torrent из Windows

Нажмите правой кнопкой на `.torrent` → «Открыть с помощью» → выберите другое приложение и укажите `qbit-remote.exe` из папки Release. Выберите использование приложения для всех файлов `.torrent`, если хотите назначить его по умолчанию. При обновлении сохраняйте путь к EXE, чтобы Windows продолжала находить приложение.

При открытии файла клиент запускается и показывает диалог выбора файлов и настроек загрузки. Добавление на выбранный сервер происходит только после подтверждения. Если клиент уже открыт, файл передаётся работающему экземпляру, а окно восстанавливается из трея. Поддерживаются несколько файлов, пробелы и кириллица в путях.

Если подключения ещё нет, клиент пытается подключиться к выбранному профилю. Файлы ожидают успешного подключения; в окне очереди можно отменить добавление или открыть настройки подключения. При первом запуске задайте адрес и учётные данные сервера. Отклонённые сервером файлы и ошибки чтения показываются как ошибки добавления.

Также можно запустить из PowerShell: `& .\qbit-remote.exe 'C:\Downloads\example.torrent'`. Старую запущенную версию нужно сначала завершить через «Файл → Выход», чтобы она уступила приём файлов новой версии.

## Выбор файлов перед добавлением

Общий диалог открывается для `.torrent` из Windows или клиента, magnet/HTTP-ссылок, результатов поиска и ручной загрузки статьи RSS. Сначала сервер получает только метаданные; содержимое торрента ещё не загружается. Для ссылки может понадобиться время на получение списка файлов. Несколько торрентов обрабатываются по очереди.

1. Проверьте имя сервера вверху и задайте папку сохранения на сервере. Пустое поле означает папку сервера по умолчанию.
2. Раскройте нужные папки и отметьте файлы для скачивания. Полные пути не повторяются в каждой строке: они доступны при наведении на имя.
3. Установите приоритеты и проверьте строку «Выбрано»: она показывает количество и общий размер выбранных файлов.
4. При необходимости раскройте «Дополнительные параметры»: там находятся категория, теги, начало очереди и последовательная загрузка.
5. Решите, нужно ли включить «Начать загрузку после добавления», и нажмите «Добавить торрент».

При растягивании диалога по вертикали дерево занимает дополнительное пространство и показывает больше файлов. Итог выбора, флажок запуска и кнопки закреплены у нижнего края; прокручивается сам список.

Названия приоритетов в строках и выпадающем меню окрашены: «Обычный» — зелёный, «Высокий» — оранжевый, «Максимальный» — красный. «Не скачивать» и сводное «Разный» показаны приглушённым цветом. Названия сохраняются, поэтому цвет не является единственным обозначением.

### Дерево и выбор папок

| Действие | Как выполнить |
| --- | --- |
| Раскрыть или свернуть папку | Нажать значок папки слева либо дважды щёлкнуть по имени папки. Ветки начиная с третьего уровня изначально свёрнуты. |
| Выбрать папку | Установить её флажок. Будут выбраны все вложенные файлы, включая скрытые поиском; уже заданные высокие приоритеты сохраняются. |
| Исключить папку | Снять её флажок. Все вложенные файлы получат «Не скачивать». |
| Понять промежуточную отметку | Часть файлов папки выбрана, часть исключена. Щелчок по такой отметке выбирает всю папку. |
| Изменить приоритет папки | Выбрать значение в её строке. Оно применяется ко всем вложенным файлам, включая скрытые поиском. |
| Понять значение «Разный» | У файлов внутри папки разные приоритеты; это сводное состояние, а не отдельный приоритет. |
| Найти файл | Ввести часть имени или пути. Подходящие ветки раскрываются автоматически; выбор файлов не меняется. |
| Управлять всем деревом | «Развернуть» и «Свернуть» меняют видимость папок; «Выбрать все» и «Снять все» меняют выбор всех файлов торрента, независимо от поиска. |

В строке папки показаны количество вложенных файлов и их суммарный размер, включая исключённые. В нижней строке «Выбрано» учитываются только файлы для скачивания. Приоритеты файлов: «Обычный», «Высокий», «Максимальный» и «Не скачивать». Если не выбран ни один файл, кнопка добавления недоступна.

### Подтверждение и запуск

Флажок «Начать загрузку после добавления» по умолчанию выключен: торрент будет добавлен остановленным. Если включить его, загрузка начнётся с выбранными файлами и приоритетами. Приоритеты и состояние запуска передаются серверу одним запросом. «Отмена» или закрытие окна до подтверждения не добавляет торрент. Автоматические правила RSS используют собственные настройки и не открывают этот диалог.

Для предварительного выбора файлов требуется qBittorrent 5.2+ с API метаданных. Сервер без этого API покажет ошибку и не начнёт загрузку автоматически. Если торрент уже есть на сервере, изменяйте его во вкладке «Файлы»: новый диалог не перезаписывает существующую загрузку. При смене подключения метаданные запрашиваются заново.

## Управление торрентами и файлами

| Действие | Как выполнить |
| --- | --- |
| Выбрать торрент | Щёлкнуть по любой части строки, включая название и прогресс. |
| Выбрать несколько | Ctrl+щелчок добавляет или снимает строку; Shift выбирает диапазон в текущем порядке сортировки; Ctrl+Shift добавляет диапазон. |
| Выбрать все / снять выбор | Ctrl+A выбирает весь видимый после фильтрации список (включая строки за пределами экрана); Escape снимает выделение. В текстовых полях Ctrl+A работает с текстом. |
| Выполнить групповую команду | Запуск, остановка и удаление — на панели, в «Правка» и контекстном меню. Остальные групповые операции и лимиты скорости — в контекстном меню. |
| Открыть команды торрента | Нажать правую кнопку мыши на его строке. Команды относятся к выделенной группе; щелчок по невыбранной строке выбирает только её. |
| Отсортировать список | Щёлкнуть по ячейке заголовка; повторный щелчок меняет направление. |
| Настроить колонки | «Вид → Колонки»; порядок меняется перетаскиванием заголовков, ширина — перетаскиванием их границ. |
| Изменить высоту сведений | Перетащить верхнюю границу нижней панели. Высота сохраняется при смене вкладок и перезапуске. |
| Раскрыть или свернуть папку | Нажать значок папки рядом с названием во вкладке «Файлы». |
| Переименовать папку | Выбрать «Переименовать папку…» в контекстном меню папки. |
| Переименовать файл | Нажать «Имя…» в строке файла. |
| Изменить приоритет файла | Выбрать значение в списке приоритетов его строки. |

При смене сервера выделение очищается. Торренты, скрытые фильтром или удалённые на сервере, исключаются из выбора. Перед групповым удалением показываются количество и названия. Панель сведений относится к последнему выбранному торренту; переименование и экспорт доступны при выборе одного торрента.

При переименовании папки форма автоматически получает её текущий относительный путь. Укажите новый путь и подтвердите изменение: операция выполняется на сервере. Отдельных кнопок переименования папок нет. Поиск по имени или пути показывает подходящие файлы с раскрытыми родительскими папками; доступны «Развернуть всё» и «Свернуть всё».

### Контекстное меню

Правый щелчок по выделенной строке открывает команды для всей выбранной группы. Если строка не выделена, выбирается только она. Сверху показано количество выбранных торрентов.

Все команды используют одинаковый размер шрифта и высоту строки. Группы обозначены приглушёнными заголовками без горизонтальных линий. Всё меню прокручивается целиком колёсиком мыши: если нижние команды не видны, прокрутите меню вниз.

| Группа | Действия |
| --- | --- |
| Основные команды | Запустить, остановить, удалить с подтверждением. |
| Проверка и трекеры | Перепроверить данные и обновить трекеры. |
| Очередь | Переместить выше, ниже, в начало или конец очереди. |
| Режим загрузки | Переключить последовательную загрузку и приоритет крайних частей у каждого выбранного торрента. |
| Управление и раздача | Принудительный запуск, автоуправление и суперсидирование. Для одного торрента галочка показывает состояние; для группы подменю предлагает включить или выключить режим у всех выбранных. |
| Данные и организация | Категории, теги, комментарий и перенос данных на сервере. Переименование доступно только для одного торрента. |
| Ограничения и экспорт | Лимиты скачивания, отдачи и раздачи. Экспорт `.torrent` доступен только для одного торрента. |

### Лимиты скорости

Для всего сервера откройте «Скорость и статистика». Для группы торрентов выберите строки, откройте контекстное меню и прокрутите до «Ограничения и экспорт». Вкладка «Общее» в нижней панели меняет лимиты только показанного в ней торрента.

Значение вводится в КиБ/с: 1024 КиБ/с = 1 МиБ/с; 0 снимает ограничение. При выборе группы один и тот же лимит устанавливается каждому торренту, а не делится между ними. Альтернативный режим переключается в разделе скорости; его значения и расписание задаются в настройках сервера.

## Свободное место на сервере

Нижняя панель оформлена одной строкой: слева — состояние подключения и имя сервера, справа — скачивание, отдача и свободное место с общим шрифтом и выравниванием. На узком окне второстепенные подписи скрываются. Версия qBittorrent доступна при наведении на состояние подключения.

Справа в строке состояния показан остаток места на диске папки загрузки по умолчанию qBittorrent. Индикатор с пиктограммой диска обновляется примерно каждые 3 секунды. Обычный остаток показан нейтральным цветом; оранжевый означает меньше 10 ГиБ, красный — меньше 1 ГиБ. При отсутствии подключения или данных отображается «—», а не нулевой остаток.

Наведите указатель на индикатор для пояснения. Значение относится к диску папки по умолчанию: другие папки загрузки могут находиться на других дисках. При переключении сервера данные предыдущего подключения сбрасываются.

## Импорт и экспорт правил RSS

Откройте «RSS → Правила автозагрузки». «Экспорт правил…» сохраняет свежий список всех правил сервера в `rss-downloader-rules.json`. Файл совместим с JSON-экспортом qBittorrent и включает имена, фильтры, URL лент и параметры торрентов.

«Импорт правил…» принимает JSON (UTF-8, до 8 МиБ), проверяет его и показывает список имён до отправки. Совпадающие имена по умолчанию пропускаются; флажок замены разрешает перезаписать их. Правила, отсутствующие в файле, не удаляются. Ленты не создаются автоматически: добавьте нужные URL на целевом сервере. Пути сохранения остаются серверными и переносятся без изменений. Включённые правила могут сразу начать загрузки.

После выполнения отображается число сохранённых и пропущенных правил. При ошибке импорт останавливается с частичным результатом: уже сохранённые правила не откатываются. Старый бинарный формат `.rss` не поддерживается — экспортируйте правила из qBittorrent в JSON.

## Оформление

Логотип и название в боковой панели объединены в один блок: он центрируется по ширине панели, а надпись — по видимым границам букв относительно значка. В «Справка → О программе» показана лесная презентация логотипа, встроенная в EXE; отдельные файлы изображений рядом с приложением не нужны.

Раздача в таблице выделена зелёным: состояние торрента, полоса прогресса и ненулевая скорость отдачи. Остановленные торренты остаются серыми, загрузка — синей.

Порядок вкладок сведений: «Общее → Файлы → Части → Пиры → Трекеры → График → HTTP-источники». На карте частей готовые сегменты зелёные, загружаемые — синие, отсутствующие — серые. Линии скачивания и отдачи на обоих графиках имеют толщину 1 точку.

Действия обозначаются чёткими цветными пиктограммами с заливкой, тонкой кромкой, бликом и мягкой тенью. Вверх и добавление — зелёные, вниз и удаление — красные; списки — серые, папки — жёлтые. Переименование, комментарии, метки, управление и лимиты имеют разные узнаваемые значки. Главный логотип имеет размер 42 точки и сопровождается названием «qBit Remote» на одной строке.

Новый логотип — тёмная скруглённая основа и крупная монограмма «qb» со встроенными стрелками: вниз у «q», вверх у «b». Голубая «q» и белая «b» обозначают загрузку и отдачу. Рядом в интерфейсе — название на одной строке: более плотное «qBit» и лёгкое «Remote». Один оригинал используется в боковой панели, окне, трее и ресурсе EXE; для малых размеров применяется масштабирование с корректной прозрачностью.

Темы выбираются в «Вид → Тема оформления» и применяются без перезапуска:

- **Graphite Theme** — тема по умолчанию: графитовые поверхности и насыщенные цветные акценты.
- **Marine Dark Theme** — тёмная сине-морская палитра с бирюзовым акцентом.
- **White Theme** — мягкие светло-серые поверхности, менее резкий текст и сдержанные акценты.

Сохранённый выбор имеет приоритет над темой по умолчанию. Масштаб 80–150% настраивается в «Вид → Масштаб интерфейса» поверх системного DPI.

## Трей и выход

Крестик по умолчанию скрывает окно в трей. Левый щелчок по значку скрывает видимое окно или показывает скрытое; свёрнутое окно восстанавливается. Правый щелчок открывает меню «Открыть qBit Remote» и «Выход». Двойной щелчок обрабатывается как одно переключение. Для завершения используйте «Файл → Выход» или «Выход» в меню значка трея.

В одной сессии Windows запускается только один экземпляр. Повторный запуск восстанавливает работающее окно, передаёт ему файлы и затем завершается.

## Обновление

Завершите приложение через «Файл → Выход», замените EXE новой версией и запустите его. Настройки хранятся отдельно от EXE. Установщика и автоматического обновления пока нет.

Порядок кнопок после поиска: добавить, запустить, остановить, удалить, выше в очереди, ниже в очереди. Стрелки меняют положение всех выделенных торрентов в очереди сервера; для этого на сервере должна быть включена очередь торрентов.

Чтобы скрыть панель информации, нажмите крестик в её правом верхнем углу или Esc. Выделение снимается; повторный выбор торрента открывает сведения с сохранённой высотой панели.

Количество выбранных торрентов отображается в нижней строке состояния непосредственно перед скоростями скачивания и отдачи. На узком окне используется подпись «Выбр.».

Сообщения действий и ошибки сохраняются в отдельной «Консоли приложения», закрытой по умолчанию. Открыть её можно правой кнопкой по строке торрента → «Консоль приложения…» либо через меню «Вид». Доступны очистка и копирование последних 300 записей. Сообщения не занимают место над таблицей. Это журнал приложения, а не командная оболочка сервера.

Стрелки очереди проверяют позиции на сервере до и после команды. Последний торрент опустить ниже нельзя; завершённые раздачи с прочерком в колонке очереди не являются следующими позициями очереди загрузки. Причина отсутствия перемещения сохраняется в консоли.
