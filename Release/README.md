# qBit Remote 0.2.12

Клиент для управления удалённым qBittorrent через Web UI API. Только Windows. Установка не требуется: запустите `qbit-remote.exe` из этой папки.

## Подключение

1. В настройках qBittorrent на сервере включите Web UI и задайте имя пользователя и пароль.
2. В клиенте откройте «Серверы → Управление серверами».
3. Укажите название профиля, адрес Web UI (например, `http://192.168.1.10:8080`), логин и пароль.
4. Нажмите «Подключиться». Для нескольких серверов создайте отдельные профили; одновременно активен один сервер.

Автоподключение к выбранному профилю включено по умолчанию. Пароль при сохранении защищается Windows DPAPI и привязывается к текущей учётной записи Windows. Для удалённого доступа используйте HTTPS или доверенный VPN; HTTP не шифрует учётные данные.

## Основные возможности

- Правый щелчок по торренту открывает сгруппированное меню действий с пиктограммами. Команды применяются к строке, по которой выполнен щелчок. Отдельной кнопки «Действия» в панели сведений нет.
- Поиск, сортировка, добавление ссылок и `.torrent`-файлов, запуск, остановка и удаление торрентов.
- 38 настраиваемых колонок через «Вид → Колонки». Видимость, порядок, ширина и сортировка сохраняются. Заголовки можно перетаскивать.
- Сведения о торренте, дерево файлов с раскрываемыми папками, приоритеты файлов, трекеры, пиры, графики и лимиты скорости.
- Темы «Graphite Theme» (по умолчанию), «Marine LLM Theme» и светлая «White Theme» через «Вид → Тема оформления». Выбор сохраняется.
- Настройки приложения — «Правка → Настройки приложения», настройки сервера — «Серверы → Настройки qBittorrent».
- Поиск через серверные плагины, RSS, журнал, категории и теги. Доступность зависит от версии и конфигурации сервера.

Пути загрузки и операции с файлами относятся к удалённому серверу. Удаление данных на сервере по умолчанию выключено и требует отдельного выбора.

## Управление торрентами и файлами

| Действие | Как выполнить |
| --- | --- |
| Выбрать торрент | Щёлкнуть по любой части строки, включая название и прогресс. |
| Открыть команды торрента | Нажать правую кнопку мыши на его строке. Команды относятся именно к этому торренту. |
| Отсортировать список | Щёлкнуть по ячейке заголовка; повторный щелчок меняет направление. |
| Настроить колонки | «Вид → Колонки»; порядок меняется перетаскиванием заголовков, ширина — перетаскиванием их границ. |
| Изменить высоту сведений | Перетащить верхнюю границу нижней панели. Высота сохраняется при смене вкладок и перезапуске. |
| Раскрыть или свернуть папку | Нажать стрелку рядом с названием во вкладке «Файлы». |
| Переименовать папку | Дважды щёлкнуть по названию либо выбрать «Переименовать папку…» в контекстном меню папки. |
| Переименовать файл | Нажать «Имя…» в строке файла. |
| Изменить приоритет файла | Выбрать значение в списке приоритетов его строки. |

Контекстное меню торрента компактное, с пиктограммами и группами команд: проверка и трекеры, очередь, режим загрузки, управление и раздача, данные и организация, ограничения и экспорт. Длинное меню прокручивается. Кнопки «Действия» в панели сведений больше нет.

При переименовании папки форма автоматически получает её текущий относительный путь. Укажите новый путь и подтвердите изменение: операция выполняется на сервере. Отдельных кнопок переименования папок нет. Поиск по имени или пути показывает подходящие файлы с раскрытыми родительскими папками; доступны «Развернуть всё» и «Свернуть всё».

## Оформление

Темы выбираются в «Вид → Тема оформления» и применяются без перезапуска:

- **Graphite Theme** — тема по умолчанию: графитовые поверхности и насыщенные цветные акценты.
- **Marine LLM Theme** — тёмная сине-морская палитра с бирюзовым акцентом.
- **White Theme** — мягкие светло-серые поверхности, менее резкий текст и сдержанные акценты.

Сохранённый выбор имеет приоритет над темой по умолчанию. Масштаб 80–150% настраивается в «Вид → Масштаб интерфейса» поверх системного DPI.

## Трей и выход

Крестик по умолчанию скрывает окно в трей. Двойной щелчок по значку возвращает окно. Для завершения используйте «Файл → Выход» или «Выход» в меню значка трея.

В одной сессии Windows запускается только один экземпляр. Повторный запуск завершается, даже если первое окно скрыто в трее.

## Обновление

Завершите приложение через «Файл → Выход», замените EXE новой версией и запустите его. Настройки хранятся отдельно от EXE. Установщика и автоматического обновления пока нет.
