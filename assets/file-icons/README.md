Общий prompt: Recreate ONLY the selected icon from the approved reference; preserve silhouette, dimensional glossy materials and perspective. Single isolated Windows file icon centered on a square transparent canvas with 6% margin. No board, number, labels (except TORRENT on the document), miniatures, background or ground shadow.

Предметы: red horseshoe magnet with brushed silver caps; white folded document with green globe and upload/download arrows; cobalt blue arrow and tray; green arrow and ivory tray; green rounded tile with white arrow and baseline; blue circular puck with white arrow and tray.

Сборка формирует ICO 16/24/32/48/64/128/256 px из тех же PNG, что использует интерфейс. Уменьшение Lanczos3 в premultiplied alpha предотвращает тёмную кайму.
