# Country flags

Source: https://flagpedia.net/download/api (https://flagcdn.com/w80/{ISO-3166-1-alpha-2}.png). Downloaded 2026-11-01.

Original flag artwork is based on Wikimedia Commons. These PNG assets are bundled locally so peer country codes are never sent to a third-party service at runtime. Original aspect ratios are preserved.

Pirate flag: Twemoji (Twitter, Inc. and other contributors), CC BY 4.0, https://github.com/jdecked/twemoji/blob/main/LICENSE-GRAPHICS and https://creativecommons.org/licenses/by/4.0/. Used unmodified.
