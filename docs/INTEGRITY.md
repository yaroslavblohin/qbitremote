# Аудит целостности 0.2.77

Исторический отчёт выпуска 0.2.77 после восстановления .github из резервной копии. Все результаты и ограничения ниже относятся к моменту этого аудита. Сейчас репозиторий Git восстановлен и публикация на GitHub работает; актуальные проверки — в [TESTING.md](TESTING.md).

## Найдено и исправлено

- В .github/workflows восстановлены Windows и macOS workflow. Добавлены предварительная проверка ресурсов, ограничения времени, явная ошибка при отсутствии артефакта. Windows запускает тесты всех feature и поддерживает ручной запуск.
- Отсутствовали assets/brand-lockup.png, brand-presentation.png, brand-suffix.png и brand-forest.png. Первые два PNG восстановлены байт в байт из исправного EXE 0.2.76 с проверкой CRC всех PNG-чанков. Исходные надпись и фон восстановлены из сохранённых оригиналов генерации.
- Повторная генерация всех девяти ресурсов бренда дала те же SHA-256. Подтверждена согласованность исходных ресурсов, геометрического генератора и встроенных изображений.
- В macOS workflow заменён retired macos-14 на macos-15 (Apple Silicon); сохранён macos-15-intel. Список runners сверен с [официальной документацией GitHub](https://github.com/actions/runner-images#available-images).
- scripts/build-macos.sh содержал CRLF. Скрипт переведён в LF, добавлена .gitattributes для сохранения LF у shell-скриптов.

## Результаты

- Проверка scripts/check-project.py: встроенные ресурсы, исходные изображения, CRC всех PNG в assets, версии пакета и документации, локальные ссылки, переносы строк — без ошибок.
- Windows: 109 тестов прошли, 6 исключены; форматирование и clippy без замечаний; release-сборка успешна.
- YAML обоих workflow разобран, проверены события запуска и структура шагов. bash -n scripts/build-macos.sh завершился успешно.
- Воспроизводимость ресурсов подтверждена SHA-256 до и после генерации. Windows UI-smoke с About завершился штатно без подключения к серверу.
- Версии Cargo.toml, собственного пакета Cargo.lock, README и Release/README согласованы. Бинарники dist и Release сверены по SHA-256; прежний выпуск архивирован с проверкой копии.

## Повторение

`python scripts/check-project.py` выполняет предварительную проверку из любой рабочей папки, используя корень относительно самого скрипта. Нужен Python 3, сторонние пакеты не требуются. `python scripts/check-project.py --release` дополнительно сравнивает SHA-256 dist/Release, проверяет состав поставки и PE-экспорт отказа от RTSS (добавлен после аудита).

Далее выполните `cargo fmt --check`, `cargo test --locked --all-features`, `cargo clippy --locked --all-targets --all-features -- -D warnings` и `cargo build --release --locked`.

## Ограничения

На момент аудита в корне рабочей папки отсутствовал .git: сравнение с историей коммитов и удалённым репозиторием не выполнялось. Успешная компиляция и проверки подтверждают работоспособность текущего набора файлов, но не доказывают отсутствие любых отличий от неизвестной резервной копии. GitHub Actions в этой сессии не запускались; workflow проверены локально. Сборка и запуск macOS требуют Mac/CI и по-прежнему не подтверждены. Нативные сценарии Проводника и циклы трея в этой задаче не повторялись.
