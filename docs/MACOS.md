# macOS — экспериментальный порт

Документация сверена с исходниками 0.2.90. Нативная сборка и запуск по-прежнему не подтверждены.

На Mac установите Xcode Command Line Tools (`xcode-select --install`) и Rust stable. Из корня проекта выполните `cargo test --locked`, затем `bash scripts/build-macos.sh`. Результат: `dist-macos/qBit Remote.app` и ZIP для архитектуры текущего Mac (Apple Silicon или Intel). CI содержит отдельные задания для обеих архитектур.

Пароли сохраняются в login Keychain; приложение может запросить доступ к связке ключей. Пароли DPAPI из Windows не переносятся — введите пароль заново. Меню значка в строке меню позволяет восстановить окно и штатно выйти. Закрытие в трей сохраняет работу приложения. Retina масштабируется средствами egui/winit. Монтируйте SMB-ресурс через Finder и сопоставьте серверный путь с `/Volumes/ИмяРесурса/...`.

Статус: исходный код порта подготовлен на Windows; сборка и запуск на macOS пока НЕ проверены. Перед выпуском требуется пройти подключение, сохранение пароля и перезапуск, добавление .torrent через диалог, Retina, меню/скрытие/выход, открытие файлов с подключённого тома. CI-файл подготовлен, но его запуск в этой сессии не выполнялся.

Ограничения первой версии: обработка Finder Open With/Apple Events и передача файлов уже запущенному экземпляру ещё не реализованы; добавляйте файлы через кнопку «+». Пиктограммы типов файлов пока резервные, не системные NSWorkspace. Windows UI-smoke использует Win32 и на Mac не запускается. Пакет имеет только ad-hoc подпись; Developer ID и notarization для публичного распространения не настроены. Универсальный бинарник не собирается: ZIP зависит от архитектуры машины сборки.
