# qBit Remote 0.3.33 для macOS

Требуется macOS 11 Big Sur или новее. Выберите архив для своего Mac.

| Mac | Архитектура | Архив |
| --- | --- | --- |
| Apple Silicon | arm64 | [qbit-remote-0.3.33-arm64.zip](../Release/qbit-remote-0.3.33-arm64.zip) |
| Intel | amd64 (x86_64) | [qbit-remote-0.3.33-amd64.zip](../Release/qbit-remote-0.3.33-amd64.zip) |

## Установка и подключение

1. Распакуйте ZIP и перенесите `qBit Remote.app` в «Программы».
2. Откройте приложение. У сборки локальная подпись ad-hoc. Если Gatekeeper блокирует первый запуск скачанного архива, после попытки запуска перейдите в «Системные настройки → Конфиденциальность и безопасность» и выберите «Всё равно открыть» для qBit Remote. [Инструкция Apple](https://support.apple.com/ru-ru/102445).
3. Включите Web UI на сервере qBittorrent. В qBit Remote откройте «Серверы → Управление серверами» и задайте адрес Web UI, имя пользователя и пароль. Нажмите «Подключиться».

При включённом сохранении пароль хранится в вашей связке ключей macOS. Система может попросить разрешение на доступ к записи. При переходе с Windows введите пароль заново.

Если сервер отключён, нажмите «Проверить подключение», чтобы повторить попытку для активной вкладки. При ошибке причина отображается под кнопками. Кнопка «Настроить подключение» открывает параметры профиля.

Если Web UI находится в локальной сети, разрешите доступ при системном запросе. На macOS 15 и новее разрешение можно проверить в разделе «Системные настройки → Конфиденциальность и безопасность → Локальная сеть». После изменения нажмите «Проверить подключение» в qBit Remote. [Описание разрешения Apple](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)

## Открытие торрентов и файлов

- Щёлкните по `.torrent` или `.magnet` в Finder правой кнопкой и выберите «Открыть в программе → qBit Remote». Можно открыть сразу несколько файлов, в том числе при скрытом окне. Файл `.magnet` может содержать ссылку `magnet:…` в UTF-8 или быть ярлыком InternetShortcut с такой ссылкой.
- Если macOS открывает magnet-ссылки в qBit Remote, ссылка поступит в очередь активного сервера. Вставить ссылку вручную или выбрать файл можно через «Файл → Добавить торрент…».
- При запуске без подключения приложение покажет очередь и предложит настроить сервер. После подключения проверьте параметры в диалоге и подтвердите добавление.
- Для открытия скачанных файлов подключите общий ресурс через Finder («Переход → Подключение к серверу», ⌘K) и добавьте сопоставление в профиле. Например, серверной папке `/downloads` может соответствовать `/Volumes/Downloads`. Приложение открывает доступный путь через системную ассоциацию.

## Ассоциации, значки и автозапуск

- В «Подключение и настройки → Значок и ассоциации файлов» выберите один из шести значков и нажмите «Применить значок и зарегистрировать ассоциации». Это назначает qBit Remote для `.torrent`, `.magnet` и magnet-ссылок. Подтвердите системный запрос, если он появится.
- После смены обработчика проверьте открытие файла двойным щелчком. В разных окнах Finder и в системном диалоге «Открыть» один и тот же файл может по-прежнему отображаться с разными значками. Чтобы вернуть штатный значок qBit Remote, примените первый вариант. Если файлу раньше назначили индивидуальный значок, откройте его «Свойства» в Finder, выделите значок вверху окна и нажмите Delete. После переноса приложения примените настройки повторно.
- Включите «Запускать при входе в macOS» в окне настроек. На macOS 13 и новее при запросе разрешения откройте «Объекты входа…». На macOS 11–12 после переноса приложения выключите и снова включите настройку, чтобы обновить путь.

## Окно и выход

Значок qBit Remote в Dock сохраняет системное оформление при запуске и после выхода. Красная кнопка по умолчанию скрывает окно. Нажмите значок qBit Remote в Dock или выберите «Открыть qBit Remote» в меню значка qbr в строке меню. macOS автоматически делает этот значок чёрным или белым в зависимости от фона. Для штатного завершения используйте ⌘Q, «Файл → Выход» или «Выход» в меню значка. Настройки хранятся в `~/Library/Application Support/qBit-Remote`.

Стрелки перед «Загрузка» и «Отдача» обозначают направления передачи. Стрелка после заголовка обозначает сортировку. Повторный щелчок по тому же заголовку меняет её направление. [Снимок списка торрентов](screenshots/v0.3.26/macos-torrents.jpg)

В окне «Подключение и настройки» масштаб применяется после отпускания ползунка. Щёлкните по ползунку, чтобы подсветить его и менять масштаб клавишами ← и → с шагом 1%. Если форма выше окна приложения, прокрутите её до ползунка.

## Сборка из исходников

Установите Xcode Command Line Tools и Rust stable. Из корня проекта выполните:

```sh
cargo test --locked
rustup target add aarch64-apple-darwin x86_64-apple-darwin
bash scripts/build-macos.sh --arm64
bash scripts/build-macos.sh --amd64
```

ZIP появятся в `dist-macos`, а пакеты приложения — в подпапках `arm64` и `amd64`. Без флага скрипт использует архитектуру среды сборки. В GitHub Actions каждому ZIP соответствует артефакт `qbit-remote-macos-arm64` или `qbit-remote-macos-amd64`. [Сборки macOS на GitHub](https://github.com/yaroslavblohin/qbitremote/actions/workflows/macos.yml)
