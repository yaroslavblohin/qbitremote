# Проверки qBit Remote 0.2.26

Дата: 30 октября 2026 года. Платформа: Windows, Rust MSVC, egui/eframe 0.31.1. Другие ОС не проверялись.

## Автоматические проверки

| Проверка | Результат |
| --- | --- |
| `cargo test --locked --all-features` | 71 прошёл, 0 ошибок, 5 исключены из прямого запуска. |
| `cargo clippy --locked --all-targets --all-features -- -D warnings` | Без предупреждений. |
| `cargo fmt --check` | Форматирование соответствует проекту. |
| `scripts/test-tray.ps1` | Три сценария, в каждом 10 циклов закрытия в трей и восстановления и 10 циклов скрытия/показа левым щелчком. Правая кнопка не меняет видимость; двойной щелчок не переключает окно повторно; свёрнутое окно восстанавливается. Штатное сохранение и выход из скрытого, открытого и свёрнутого окна. |

Из пяти исключённых тестов три требуют явно заданных учётных данных реального сервера. Два других — вспомогательные дочерние процессы: они запускаются и проверяются родительскими тестами защиты от второго экземпляра и передачи файлов. Проверки рабочего сервера в этом наборе не запускались; изменения торрентов и настроек проверялись через локальный HTTP mock-сервер.

## Дополнительное покрытие

| Сценарий | Что проверяется |
| --- | --- |
| Полный диалог с раскрытыми настройками | UI-события нажимают заголовок настроек и перетаскивают нижний угол окна; дерево растёт, итог и кнопки следуют за нижним краем, строки не перекрывают кнопки. |
| Две ширины и две высоты | При увеличении высоты с 360 до 680 точек растёт видимая область списка; проверены ширины 540 и 900 точек. |
| Пустой результат поиска | Выбор остаётся прежним; подтверждение передаёт все выбранные файлы, отмена не формирует команду добавления. |
| Недоступная кнопка добавления | Реальные UI-щелчки не создают новый запрос, если ничего не выбрано или предыдущий запрос уже выполняется. |
| Неверный план и все файлы исключены | Проверка завершается до отправки запросов изменения торрентов серверу. |
| Дерево на 5000 файлах | Сортировка, поиск и сворачивание сохраняют исходные индексы файлов для API, итоговый размер и количество выбранных файлов. |
| Папки `Pack` и `Package` | Приоритет `Pack` применяется также к скрытым поиском потомкам, включая пути с обратными слешами и кириллицей, но не меняет соседнюю папку `Package`. |
| Кнопки мыши в трее | Переключение только при отпускании левой кнопки; правая и средняя кнопки не переключают окно. |
| Двойной щелчок в трее | Последовательность Windows Down → Up → DoubleClick → Up переключает окно один раз; следующий одиночный щелчок продолжает работать. |
| Частично выбранная папка | Щелчок выбирает всех потомков и сохраняет уже назначенные высокие приоритеты. |

Геометрия диалога и щелчки проверяются непосредственно в egui, без сетевого сервера. Нативная проверка трея запускает отдельный Windows-процесс в демонстрационном режиме; штатный клиент пользователя не завершается. События мыши программно передаются производственному обработчику. Настоящие клики по значку и показ меню не автоматизированы; для ручной приёмки левый щелчок должен переключать окно без меню, правый — открывать меню без переключения окна.

## Повторение проверок

Запускайте из корня проекта; для нативных сценариев требуется рабочий стол Windows.

```powershell
cargo fmt --check
cargo test --locked --all-features
cargo clippy --locked --all-targets --all-features -- -D warnings
./scripts/test-tray.ps1
```

Для адресного повторения проверок диалога:

```powershell
cargo test --locked expanded_dialog_resizes
cargo test --locked empty_search_keeps
cargo test --locked disabled_add_never
cargo test --locked five_thousand_files
```

## Демонстрационные окна и снимки

`scripts/update-screenshots.ps1` создаёт девять кадров текущей версии: список торрентов, файлы, скорость, Graphite, White, контекстное меню, множественный выбор, импорт RSS и диалог добавления. Они используют фиктивные данные; пароль и настройки рабочего сервера не нужны.

Для этого выпуска девять кадров сформированы заново. Дополнительно проверены окно высотой 650 точек с 205 файлами в Graphite и окно высотой 360 точек в White при масштабе 150%: кнопки доступны, область файлов меняет высоту, цветные подписи приоритетов читаются. Снимки этих двух сценариев сохранены в `dist/test-dialog-large.png` и `dist/test-dialog-hidpi.png`; это генерируемые материалы проверки, не часть папки Release.

Чтобы проверить высокий диалог с 205 демонстрационными файлами:

```powershell
$env:QBIT_SMOKE_PAGE = 'add-torrent'
$env:QBIT_SMOKE_ADD_MANY = '1'
$env:QBIT_SMOKE_ADD_HEIGHT = '650'
$env:QBIT_SMOKE_ZOOM = '1'
$env:QBIT_SMOKE_THEME = 'graphite'
Remove-Item -LiteralPath dist/ui-smoke-state.ron -ErrorAction SilentlyContinue
cargo run --locked --features ui-smoke
```

Для маленького окна при увеличенном масштабе задайте высоту `360`, масштаб `1.5` и тему `white`, снова очистите тестовый файл состояния и повторите запуск. Снимок сохраняется в `dist/ui-smoke.png`; тестовое окно завершается автоматически. Эти переменные относятся только к сборке с `ui-smoke`. Файл `dist/ui-smoke-state.ron` содержит исключительно состояние демонстрационного окна.

После ручной проверки удалите переменные `QBIT_SMOKE_PAGE`, `QBIT_SMOKE_ADD_MANY`, `QBIT_SMOKE_ADD_HEIGHT`, `QBIT_SMOKE_ZOOM` и `QBIT_SMOKE_THEME` из текущей сессии PowerShell. Скрипт обновления снимков сохраняет и восстанавливает прежние значения сам.

## Границы проверки

Тесты HTTP проверяют кодирование и последовательность запросов, ответы и отказы API, но не заменяют приёмку загрузки на конкретной версии сервера. Предварительный выбор файлов требует qBittorrent 5.2+ с API метаданных. Выбор новых данных для фактического скачивания на рабочем сервере в рамках этих дополнительных проверок не выполнялся.
