# Проверки qBit Remote 0.3.0

Последний полный прогон: 7 ноября 2026 года, Windows, Rust MSVC, egui/eframe 0.31.1. Для 0.3.0 повторены тесты, форматирование, clippy и release-сборка; обновлены 22 демонстрационных снимка.

| Проверка | Последний результат |
| --- | --- |
| `cargo test --locked --all-features` | 123 прошли, 6 исключены из прямого запуска |
| `cargo fmt --check` | Без замечаний |
| `cargo clippy --locked --all-targets --all-features -- -D warnings` | Без предупреждений |
| `cargo build --release --locked` | Успешно |
| `python scripts/check-project.py --release` | Ресурсы, версии, ссылки, SHA-256 и экспорт RTSS согласованы |

Из шести исключённых тестов три требуют учётных данных реального сервера, один открывает Проводник, два служат дочерними процессами и вызываются родительскими тестами. Полный прогон не выполняет три live API-теста. HTTP-команды проверяются на локальном mock-сервере.

Геометрия диалога и щелчки проверяются непосредственно в egui, без сетевого сервера. Нативная проверка трея запускает отдельный Windows-процесс в демонстрационном режиме; штатный клиент пользователя не завершается. События мыши программно передаются производственному обработчику. Настоящие клики по значку и показ меню не автоматизированы; для ручной приёмки левый щелчок должен переключать окно без меню, правый — открывать меню без переключения окна.

## Дополнительные регрессии

- Резкость логотипа: усиление локального контраста без изменения альфа-канала и тёмных ореолов; кэш по физическому размеру и однозначная выборка пикселей без повторного размытия.

- Приоритеты: UI-тест сравнивает FontId выбранного значения и всех пунктов меню. Кнопка папки использует общий проверенный путь content_path и режим Folder: папка открывается непосредственно, для файла выбирается родитель.

- Числовые свойства и лимиты: неизвестные отрицательные значения, различие `-1`/`-2`/0 для шести лимитов раздачи, дробный ratio и сохранение единиц скоростных ограничений.

- Общая доступность торрента: прочерк и подсказка при неизвестном значении, сохранение нуля и положительного числа распределённых копий без перевода в проценты.

- Доступность файла: неизвестное значение при прогрессе 100%, нулевая/частичная/полная доступность, отдельная подсказка папки и сохранение единиц распределённых копий для торрента.

- Начальное дерево файлов: раскрытие только корней, свёрнутые вложенные папки, несколько корней и отдельные файлы; поиск не изменяет начальное состояние, ручное раскрытие оставляет более глубокие папки свёрнутыми.

- Графики: запись отдельно для каждого торрента и общего графика, по умолчанию выключена; независимые истории и масштаб, фоновые замеры, освобождение памяти, прореживание с сохранением пиков.
- Свойства: удаление смысловых дублей и заполнение null; перенос длинных значений, согласованные колонки и прокрутка у правого края.
- URI: HTTP/HTTPS, magnet и UDP, копирование, открытие и отмена на перенесённых строках. Проверяется событие открытия, внешнее приложение не запускается. Те же действия проверены для однострочных сокращённых адресов таблицы трекеров: открытие и копирование сохраняют весь URI.
- Приоритеты: единый размер и центрирование кнопок и пунктов меню, цвета во всех темах, применение к скрытым потомкам папки.
- Выбор и очередь: фильтры, диапазоны, контекстное меню, границы очереди и HTTP-успех без изменения позиции; консоль ограничена 300 записями.
- Оформление: счётчики, геометрия полос паузы, флаги стран, сохранение типов параметров настроек, центрирование логотипа и симметрия монограммы.
- Сглаживание: уменьшение прозрачной диагонали без тёмного ореола. Проверка выпуска разбирает PE-экспорт `RTSSHooksCompatibility` и проверяет нулевой DWORD.

## Демонстрационные окна и снимки

`scripts/update-screenshots.ps1` создаёт 22 кадра текущей версии: список торрентов, файлы, трекеры, скорость, Graphite, White, контекстное меню, множественный выбор, импорт RSS и диалог добавления, а также отдельные снимки сопоставлений, открытия файлов и строки состояния. Они используют фиктивные данные; пароль и настройки рабочего сервера не нужны.

Чтобы проверить высокий диалог с 205 демонстрационными файлами:

```powershell
$env:QBIT_SMOKE_PAGE = 'add-torrent'
$env:QBIT_SMOKE_ADD_MANY = '1'
$env:QBIT_SMOKE_ADD_HEIGHT = '650'
$env:QBIT_SMOKE_ZOOM = '1'
$env:QBIT_SMOKE_THEME = 'graphite'
Remove-Item -LiteralPath dist/ui-smoke-state.ron -ErrorAction SilentlyContinue
cargo run --locked --features ui-smoke
```

Для маленького окна при увеличенном масштабе задайте высоту `360`, масштаб `1.5` и тему `white`, снова очистите тестовый файл состояния и повторите запуск. Снимок сохраняется в `dist/ui-smoke.png`; тестовое окно завершается автоматически. Эти переменные относятся только к сборке с `ui-smoke`. Файл `dist/ui-smoke-state.ron` содержит исключительно состояние демонстрационного окна.

После ручной проверки удалите переменные `QBIT_SMOKE_PAGE`, `QBIT_SMOKE_ADD_MANY`, `QBIT_SMOKE_ADD_HEIGHT`, `QBIT_SMOKE_ZOOM` и `QBIT_SMOKE_THEME` из текущей сессии PowerShell. Скрипт обновления снимков сохраняет и восстанавливает прежние значения сам.

## Нативная проверка RTSS — 7 ноября 2026 года

На Windows проверена опубликованная сборка 0.2.89 из `dist/qbit-remote.exe` при работающем RivaTuner Statistics Server. Через Computer Use проверено видимое окно: OSD отсутствует сразу после запуска и при повторном осмотре через 34 секунды. Эта задержка превышает установленные в локальном профиле RTSS 15 секунд. Логотип отображается со сглаживанием; настройки и профили RTSS не менялись. Принудительный ForceHooking не проверялся и может переопределить отказ приложения.

Предыдущая ошибка запуска помощника CreateProcessSecurityEnvironment (0x80070057) при повторной проверке больше не возникала. Причина её исчезновения не установлена. Проверка RTSS относится к сборке 0.2.89; в 0.2.90 изменены документация и номер версии, код отказа от RTSS и сглаживания не менялся.
